数学原理
核心公式
加权求和
z = Σ wᵢxᵢ = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ
输入 xᵢ ∈ {0, 1}，权重 wᵢ ∈ ℝ
阶跃激活函数
y = f(z) = { 1 if z ≥ θ { 0 if z < θ
f 是阶跃函数（step function），输出 y ∈ {0, 1}
逻辑门参数
AND: w₁=1, w₂=1, θ=1.5 → y=1 仅当 x₁=1 且 x₂=1
OR: w₁=1, w₂=1, θ=0.5 → y=1 当 x₁=1 或 x₂=1
NOT: w₁=-1, θ=-0.5 → y=1 当 x₁=0
通过调整权重和阈值，同一模型结构可实现不同逻辑运算
代码实现
Python 核心逻辑
Python · mp_neuron.py 
import numpy as np

class MPNeuron:
    def __init__(self, weights, threshold):
        self.weights = np.array(weights)
        self.threshold = threshold

    def forward(self, x):
        # 加权求和
        z = np.dot(self.weights, x)
        # 阶跃激活
        return 1 if z >= self.threshold else 0

# AND门: w=[1,1], θ=1.5
and_gate = MPNeuron([1, 1], 1.5)
print(and_gate.forward([1, 1]))  # → 1
print(and_gate.forward([1, 0]))  # → 0

历史意义
局限性与影响

历史局限

• 只能处理二值输入输出，实际神经元是连续值的
• 没有学习机制，权重和阈值需手动设置
• 无法学习异或（XOR）——线性不可分问题
• 阶跃函数不可微，无法使用梯度下降训练

历史影响

• 直接启发了 Rosenblatt 的感知机（1957）
• 奠定了所有人工神经网络研究的基础
• 开启了神经网络与逻辑学的结合研究
• 证明了数学形式化表达神经活动是可行的

学习心得
关键洞察

学到的知识

  • MP神经元是第一个数学形式的神经网络模型
  • 只能处理 0 和 1 的二值输入输出
  • 可以通过设置权重实现 AND、OR、NOT 等逻辑门
  • 单层MP神经元无法解决 XOR 问题（线性不可分）

思考题答案

  • 为什么不能解决XOR？ XOR是线性不可分问题，单层感知机只能学习线性分类器
  • 如何扩展为连续值输出？ 使用阶跃函数的连续近似，如sigmoid函数
  • 阶跃函数不可微的影响？ 无法使用梯度下降训练，这是感知机需要解决的问题
