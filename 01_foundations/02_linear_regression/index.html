历史背景
从天体轨道到机器学习

1809年，卡尔·弗里德里希·高斯发表了《天体运动理论》，提出最小二乘法预测谷神星轨道。同年，阿德里安·勒让德独立发表该方法。

两个多世纪后，线性回归仍是数据科学中最广泛使用的基线模型。

数学原理
两种求解路径
模型定义
y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wᵀx + b
损失函数（MSE）
J(w,b) = (1/n) · Σ(yᵢ − (wᵀxᵢ + b))²
均方误差：预测值与真实值之差的平方的均值

解析解（正规方程）

直接求出全局最优解，无需迭代。

w = (XᵀX)⁻¹Xᵀy

优点：精确解 · 缺点：O(n³)复杂度

梯度下降

迭代逼近最优解，适合大规模数据。

w := w − α · ∂J/∂w
∂J/∂w = (2/n) · Xᵀ(Xw + b − y)

优点：可扩展 · 缺点：需调学习率

class LinearRegression:
    def __init__(self, lr=0.01, max_iter=1000):
        self.lr = lr
        self.max_iter = max_iter
        self.weights = None
        self.bias = None

    def fit(self, X, y, method="closed_form"):
        if method == "closed_form":
            X_b = np.hstack([np.ones((X.shape[0], 1)), X])
            self.weights = np.linalg.pinv(X_b.T @ X_b) @ X_b.T @ y
            self.bias = self.weights[0]
            self.weights = self.weights[1:]

    def predict(self, X):
        return X @ self.weights + self.bias

    def score(self, X, y):
        y_pred = self.predict(X)
        ss_res = np.sum((y - y_pred) ** 2)
        ss_tot = np.sum((y - np.mean(y)) ** 2)
        return 1 - ss_res / ss_tot
