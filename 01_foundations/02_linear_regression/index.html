历史背景
从问题到突破

Carl Friedrich Gauss 与 Adrien-Marie Legendre 在 1809 年独立提出了最小二乘法，用于天体轨道的计算。这是机器学习发展史上最早的系统性方法之一。

1795
高斯的预见
Gauss 在少年时期就用最小二乘法预测了谷神星的轨道，但未发表方法。
1805
Legendre 首次发表
Legendre 在《彗星轨道新确定法》中首次公开发布最小二乘法，命名为 \"least squares\"。
1809
Gauss 的严格证明
Gauss 在《天体运动论》中给出了最小二乘法的概率论证明，确立了其理论基础。
19世纪中叶
广泛应用
最小二乘法被广泛应用于大地测量、气象学和经济学等领域，成为科学计算的基石。
数学原理
核心公式
模型定义
y = wᵀx + b
目标变量 y 是输入特征 x 的线性组合，w 为权重向量，b 为偏置项。
损失函数 — 均方误差 (MSE)
J(w, b) = ¼∑(yᵢ - (wᵀxᵢ + b))²
最小化残差平方和，使预测值与真实值之间的差距最小。
方法一：正规方程（解析解）
w = (XᵀX)-1Xᵀy
直接求解，无需迭代；但当特征数很大时，O(n³) 的矩阵求逆代价较高。
方法二：梯度下降
w := w - α · ∂J/∂w
梯度 ∂J/∂w = -(2/n)Xᵀ(y - Xw)，需要仔细选择学习率 α。

class LinearRegression:
    def __init__(self, lr=0.01, max_iter=1000):
        self.lr = lr
        self.max_iter = max_iter
        self.weights = None
        self.bias = None

    def fit_closed_form(self, X, y):
        # 正规方程: w = (XᵀX)⁻¹Xᵀy
        Xb = np.hstack([np.ones((X.shape[0], 1)), X])
        self.weights = np.linalg.pinv(Xb.T @ Xb) @ Xb.T @ y
        self.bias = self.weights[0]
        self.weights = self.weights[1:]

    def fit_gd(self, X, y):
        # 梯度下降迭代更新
        self.weights = np.zeros(X.shape[1])
        self.bias = 0
        for i in range(self.max_iter):
            pred = X @ self.weights + self.bias
            error = pred - y
            self.weights -= self.lr * (2/len(y)) * X.T @ error
            self.bias -= self.lr * (2/len(y)) * sum(error)

    def predict(self, X):
        return X @ self.weights + self.bias

    def score(self, X, y):
        # R² 分数
        ss_res = sum((y - self.predict(X))**2)
        ss_tot = sum((y - np.mean(y))**2)
        return 1 - ss_res / ss_tot

局限性
已知约束

只能捕捉线性关系

无法处理非线性问题，对于复杂的模式拟合效果有限。

对异常值敏感

MSE 损失函数对离群点放大了影响，单个异常值可显著偏移拟合线。

假设特征独立

忽略了特征之间的相关性（共线性），可能引入估计偏差。

需要特征缩放

不同量纲的特征会影响梯度下降的收敛速度，正规方程不受影响。

关键洞察

学到的知识

  • 最小二乘法：线性回归的标准解法，具有闭式解
  • 两种求解方法：解析解（正规方程）和梯度下降，各有适用场景
  • 特征缩放的重要性：不同量纲的特征会影响梯度下降收敛速度
  • R² 分数：衡量回归模型性能的标准指标，取值范围 (-∞, 1]

踩坑记录

  • 正规方程在特征数量很大时计算成本高（O(n³)），此时应改用梯度下降
  • 梯度下降需要仔细选择学习率——太大不收敛，太小太慢

思考题

  • 为什么需要特征缩放？答：不同量纲导致梯度方向偏向大数值特征，收敛变慢
  • 正则化如何改善线性回归？答：岭回归(L2)防过拟合，Lasso(L1)做特征选择
  • 岭回归和Lasso回归有什么区别？答：L2缩小权重但不归零，L1可将部分权重压缩为零
