# 线性回归学习心得

## 学到的知识

1. **最小二乘法**：线性回归的标准解法
2. **两种求解方法**：解析解（正规方程）和梯度下降
3. **特征缩放的重要性**：不同量纲的特征会影响收敛速度
4. **R²分数**：衡量回归模型性能的标准指标

## 踩坑记录

- 正规方程在特征数量很大时计算成本高（O(n³)）
- 梯度下降需要仔细选择学习率

## 思考题答案

1. **为什么需要特征缩放？**
   - 不同量纲的特征会导致梯度下降收敛缓慢
   - 解析解不受影响，但数值稳定性可能受影响

2. **正则化如何改善线性回归？**
   - 岭回归（L2）：防止过拟合，处理共线性
   - Lasso回归（L1）：特征选择，产生稀疏解

3. **岭回归和Lasso回归有什么区别？**
   - 岭回归：L2正则化，权重缩小但不为零
   - Lasso回归：L1正则化，可以将某些权重压缩为零
