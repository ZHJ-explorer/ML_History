从问题到突破

Sir David Cox 于 1958 年提出逻辑回归，这是机器学习发展史上的一个重要里程碑。

逻辑回归是二分类问题的经典算法，它是线性回归的自然扩展，通过 Sigmoid 函数将线性输出映射到概率空间。

当时的问题

线性回归不适合分类问题，输出可能超出 [0,1] 范围；需要一种能够输出概率的模型。

核心突破

Sigmoid 函数将任意实数映射到 (0,1) 区间；对数似然损失函数易于优化。

数学原理
Sigmoid 函数曲线

Sigmoid 函数将任意实数映射到 (0, 1) 区间，是逻辑回归的核心激活函数。

图: Sigmoid 函数 g(z) = 1 / (1 + e^{-z})，关键点 (0, 0.5) 为拐点与决策边界

数学原理
核心公式
模型定义 · 假设函数
h_θ(x) = g(θᵀx),   g(z) = 1 / (1 + e^{-z})
Sigmoid 函数将任意实数映射到 (0, 1)，输出可解释为概率
损失函数 · 对数损失 (Log Loss)
J(θ) = −(1/m) Σ [y(i)·log(h(x(i))) + (1−y(i))·log(1−h(x(i)))]
凸函数，全局最优可通过梯度下降求得
梯度更新
θ := θ − α · (1/m) Σ (h(x(i)) − y(i)) · xj(i)
形式与线性回归相同，但 h(x) 是经过 Sigmoid 的非线性输出

import torch
import torch.nn as nn
import torch.nn.functional as F

class LogisticRegression(nn.Module):
    def __init__(self, input_dim):
        super().__span class="fn">init__()
        self.linear = nn.Linear(input_dim, 1)

    def forward(self, x):
        # 线性层 + Sigmoid 激活
        z = self.linear(x)
        return torch.sigmoid(z)

# 对数损失（Binary Cross Entropy）
criterion = nn.BCELoss()

评价
局限性与影响

局限性

  • → 只能处理线性可分问题
  • → 对异常值敏感
  • → 需要特征缩放

历史影响

  • → 医学诊断、信用评分等领域的标准方法
  • → 后续所有分类算法的基础
  • → 神经网络中 sigmoid 单元的起源
学习心得
关键洞察

学到的知识

  • Sigmoid 函数将线性输出映射到概率空间
  • 对数损失函数适合二分类问题
  • 梯度下降的更新公式与线性回归形式类似

踩坑记录

  • Sigmoid 函数需要 clip 防止溢出
  • 需要特征缩放

思考题答案

  • 为什么逻辑回归使用 Sigmoid 而不是阶跃函数？ — 阶跃函数不可微，无法使用梯度下降
  • 逻辑回归与线性回归的本质区别是什么？ — 逻辑回归通过 Sigmoid 将输出限制在 [0,1] 用于分类；线性回归直接输出连续值用于回归
