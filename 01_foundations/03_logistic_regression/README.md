# 逻辑回归

## 历史背景

逻辑回归是二分类问题的经典算法，最早由Sir David Cox于1958年提出。它是线性回归的自然扩展，通过sigmoid函数将线性输出映射到概率空间。

**当时的问题**：
- 线性回归不适合分类问题，输出可能超出[0,1]范围
- 需要一种能够输出概率的模型

**核心突破**：
- Sigmoid函数将任意实数映射到(0,1)区间
- 对数似然损失函数易于优化

## 数学原理

### 模型定义

$$h_\theta(x) = g(\theta^T x)$$

其中 $g(z) = \frac{1}{1 + e^{-z}}$ 是sigmoid函数。

### 损失函数

使用对数损失（log loss）：

$$J(\theta) = -\frac{1}{m}\sum_{i=1}^{m}[y^{(i)}\log(h_\theta(x^{(i)})) + (1-y^{(i)})\log(1-h_\theta(x^{(i)}))]$$

### 梯度更新

$$\theta := \theta - \alpha \frac{\partial J}{\partial \theta}$$

其中：

$$\frac{\partial J}{\partial \theta_j} = \frac{1}{m}\sum_{i=1}^{m}(h_\theta(x^{(i)}) - y^{(i)})x_j^{(i)}$$

## 历史局限性

1. 只能处理线性可分问题
2. 对异常值敏感
3. 需要特征缩放

## 历史影响

- 医学诊断、信用评分等领域的标准方法
- 后续所有分类算法的基础
