# 感知机

## 历史背景

1957年，Frank Rosenblatt在康奈尔航空实验室开发了感知机（Perceptron），这是第一个能够学习的神经网络模型。感知机的提出标志着神经网络研究的第一个高潮。

**当时的问题**：
- MP神经元没有学习机制，需要手动设置权重
- 需要一种能够自动学习的模型

**核心突破**：
- 感知机学习规则（Perceptron Learning Rule）
- 证明了如果数据线性可分，感知机会收敛

## 数学原理

### 模型结构

$$y = f(\sum_{i=1}^{n} w_i x_i + b)$$

其中 $f$ 是阶跃函数。

### 学习规则

当预测错误时更新权重：

$$w_i := w_i + \eta(y_i - \hat{y}_i)x_i$$

$$b := b + \eta(y_i - \hat{y}_i)$$

其中 $\eta$ 是学习率。

### 收敛性定理

如果训练数据线性可分，感知机算法一定收敛。

## 历史局限性

1. 只能解决线性可分问题
2. 无法解决XOR问题
3. Minsky和Papert的批评导致神经网络研究寒冬

## 历史影响

- 直接启发了多层感知机和反向传播算法
- 为支持向量机的发展奠定基础
