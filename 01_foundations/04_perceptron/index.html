历史背景
从 MP 神经元到感知机

Frank Rosenblatt 于 1957 年在康奈尔航空实验室提出感知机，这是第一个能够自动学习的神经网络模型，标志着神经网络研究的第一个高潮。

当时的问题

MP 神经元没有学习机制，权重需要手动设置。科学家需要一种能够自动从数据中学习的模型。

核心突破

感知机学习规则（Perceptron Learning Rule）：根据预测误差自动调整权重，并严格证明了对线性可分数据必定收敛。

数学原理
核心公式
模型定义 · 阶跃激活
ŷ = f(w·x + b),   f(z) = 1 if z ≥ 0,   0 otherwise
将线性组合通过阶跃函数映射为二值输出 {0, 1}
感知机学习规则
wi := wi + η · (y − ŷ) · xi
b := b + η · (y − ŷ)
仅在预测错误时更新权重；η 为学习率，控制更新步长
收敛性定理
若训练数据 线性可分，则感知机算法必定收敛，
且迭代次数上界为   (R / γ)2
R = 样本最大范数，γ = 间隔（margin）。Minsky & Papert (1969) 指出 XOR 线性不可分，导致感知机研究陷入低谷。
代码实现
NumPy 核心实现
Python · model.py 
import numpy as np

class Perceptron:
    def __init__(self, lr=0.01, max_iter=100):
        self.lr = lr
        self.max_iter = max_iter
        self.weights = None
        self.bias = None

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0
        for _ in range(self.max_iter):
            errors = 0
            for xi, target in zip(X, y):
                pred = 1 if np.dot(xi, self.weights) + self.bias >= 0 else 0
                update = self.lr * (target - pred)
                self.weights += update * xi
                self.bias += update
                if update != 0: errors += 1
            if errors == 0: break
        return self

评价
局限性与历史影响

局限性

  • → 只能解决线性可分问题
  • → 无法解决 XOR 等非线性问题
  • → 阶跃函数不可微，无法用梯度下降

历史影响

  • → 直接启发了多层感知机（MLP）
  • → 为反向传播算法奠定基础
  • → 为支持向量机（SVM）的发展铺路
学习心得
关键洞察

学到的知识

  • 感知机学习规则：根据错误自动调整权重，无需手动设定
  • 收敛性定理：线性可分数据保证感知机必定收敛
  • 无法解决 XOR 问题——单层感知机只能学习线性分类器

踩坑记录

  • 需要多次遍历数据直到收敛（errors == 0 才停止）
  • 学习率太大可能导致权重震荡不收敛

思考题答案

  • 为什么感知机不能解决 XOR 问题？ — XOR 是线性不可分问题，单层感知机只能学习线性分类器
  • 如何改进感知机以解决非线性问题？ — 使用多层感知机（MLP），引入非线性激活函数和反向传播
