# k-Means聚类

## 历史背景

k-Means算法由Stuart Lloyd于1957年提出，是最经典的聚类算法。它是一种无监督学习方法，用于将数据分成k个簇。

**核心思想**：
- 给定k个初始中心，迭代优化直到收敛
- 每次迭代分为两步：分配和更新

## 数学原理

### 目标函数

最小化簇内平方和：

$$J = \sum_{i=1}^{k} \sum_{x \in C_i} ||x - \mu_i||^2$$

其中 $\mu_i$ 是簇 $C_i$ 的中心。

### 算法步骤

1. 初始化k个中心点
2. 分配：将每个点分配到最近的中心
3. 更新：重新计算中心点
4. 重复步骤2-3直到收敛

## 历史局限性

1. 需要预先指定k值
2. 对初始中心敏感
3. 只能发现球形簇
4. 对异常值敏感

## 历史影响

- 后续发展出多种改进算法：k-Medoids、Fuzzy C-Means等
- 仍是基准聚类算法
