历史背景
从问题到突破

数学原理
目标函数与算法步骤
目标函数 · 簇内平方和 (WCSS)
J = Σᵢ₌₁ᵏ  Σₓ∈Cᵢ  ||x − μᵢ||²
其中 μᵢ 是簇 Cᵢ 的中心（质心），目标是使所有点到其质心的距离平方和最小
分配步骤
cᵢ ← argminⱼ  ||xᵢ − μⱼ||²
将每个点分配到距离最近的质心所在的簇
更新步骤
μⱼ ← (1 / |Cⱼ|)  Σₓ∈Cⱼ  x
对每个簇，重新计算所有点的均值作为新的质心
💡 关键洞察

k-Means 是高斯混合模型 (GMM) 的特殊情况：当每个簇的协方差矩阵为球形且方差相等时，GMM 退化为 k-Means。这解释了为什么 k-Means 只能发现球形簇。

代码实现
核心算法逻辑
Python · kmeans.py 
import numpy as np

class KMeans:
    def __init__(self, k=3, max_iter=300, tol=1e-4):
        self.k = k
        self.max_iter = max_iter
        self.tol = tol

    def fit(self, X):
        # 1. 初始化质心（随机选取）
        idx = np.random.choice(X.shape[0], self.k, replace=False)
        self.centroids = X[idx].copy()

        for i in range(self.max_iter):
            # 2. 分配：每个点 → 最近质心
            dists = np.linalg.norm(X[:, None] - self.centroids, axis=2)
            labels = np.argmin(dists, axis=1)

            # 3. 更新：重新计算质心
            new_centroids = np.array([X[labels == j].mean(axis=0)
                                      for j in range(self.k)])

            # 4. 检查收敛
            shift = np.linalg.norm(new_centroids - self.centroids)
            self.centroids = new_centroids
            if shift < self.tol:
                break

        self.labels = labels
        return self

    def inertia(self):
        # 簇内平方和（衡量聚类质量）
        return sum(np.linalg.norm(X[self.labels == j] - self.centroids[j]) ** 2
                   for j in range(self.k))

学习心得
关键洞察

学到的知识

  • 无监督学习：不需要标签，算法自动发现数据结构
  • 迭代优化：分配和更新交替进行，逐步收敛到局部最优
  • 惯性 (Inertia)：衡量聚类质量的指标，即簇内平方和，可用于肘部法则选 k

踩坑记录

  • 对初始质心敏感，建议多次运行取最优结果
  • 特征缩放很重要，不同量纲的特征会干扰距离计算

思考题答案

  • 如何选择 k？ — 肘部法则（观察惯性随 k 变化的拐点）、轮廓系数、业务理解
  • 如何改进初始中心选取？ — k-Means++ 策略（稀疏化初始中心），或多运行取最优
  • k-Means 与 GMM 的关系？ — k-Means 是 GMM 的特例：球形协方差 + 等方差约束
