# k近邻（k-NN）

## 历史背景

k近邻是最简单的机器学习算法之一，最早由Evelyn Fix和JD Hodges于1951年提出。它是一种基于实例的学习算法，没有明确的训练过程。

**核心思想**：
- 近朱者赤，近墨者黑
- 相似的事物应该有相似的输出

## 数学原理

### 距离度量

常用距离：
- 欧氏距离：$d(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$
- 曼哈顿距离：$d(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^{n}|x_i - y_i|$
- 闵可夫斯基距离：$d(\mathbf{x}, \mathbf{y}) = (\sum_{i=1}^{n}|x_i - y_i|^p)^{1/p}$

### 预测规则

给定测试样本 $\mathbf{x}$，找到训练集中距离最近的k个样本，取多数投票：

$$\hat{y} = \arg\max_c \sum_{i \in N_k(\mathbf{x})} \mathbb{I}(y_i = c)$$

## 历史局限性

1. 计算成本高：预测时需要计算与所有训练样本的距离
2. 对高维数据效果差：维度灾难
3. 需要选择超参数k
4. 对噪声敏感

## 历史影响

- 简单的基准方法
- 模板匹配的基础
- 后续发展出多种变体
