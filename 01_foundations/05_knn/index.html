k近邻（k-NN）

k近邻是最简单的机器学习算法之一，最早由Evelyn Fix和JD Hodges于1951年提出。它是一种基于实例的学习算法，没有明确的训练过程。 **核心思想**： - 近朱者赤，近墨者黑 - 相似的事物应该有相似的输出 常用距离： - 欧氏距离：$d(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$

    class KNN:
    """k近邻分类器。"""
    def __init__(self, k=3, distance='euclidean'):
        self.k = k
        self.distance = distance
        self.X_train = None
        self.y_train = None

    def fit(self, X, y):
        self.X_train = np.array(X)
        self.y_train = np.array(y)
        return self

    def _distance(self, x1, x2):
        if self.distance == 'euclidean':
            return np.sqrt(np.sum((x1 - x2) ** 2))
        elif self.distance == 'manhattan':
            return np.sum(np.abs(x1 - x2))
        else:
            raise ValueError(f"不支持的距离度量: {self.distance}")

    def predict(self, X):
        return np.array([self._predict_one(x) for x in X])

    def _predict_one(self, x):
        distances = [self._distance(x, x_train) for x_train in self.X_train]
        k_indices = np.argsort(distances)[:self.k]
        k_nearest_labels = self.y_train[k_indices]
        most_common = Counter(k_nearest_labels).most_common(1)
        return most_common[0][0]

    def score(self, X, y):
        return np.mean(self.predict(X) == y)

    局限性
    为什么它不够好

    1. 计算成本高：预测时需要计算与所有训练样本的距离

    2. 对高维数据效果差：维度灾难

    3. 需要选择超参数k

    4. 对噪声敏感

    历史影响

    从实践中学习

    学到的知识

      1. 没有显式训练过程，直接存储训练数据

      2. k值选择很重要：太小对噪声敏感，太大会平滑边界

      3. 距离度量影响结果

    思考题答案

      1. **k值如何选择？**

    • → 通常取奇数避免平局
    • → 通过交叉验证选择
    • → 经验法则：k ≈ sqrt(n)

      • 2. **距离度量如何选择？**

    • → 欧氏距离：最常用的默认选择
    • → 曼哈顿距离：高维空间更稳定
    • → 根据数据特性选择
