k近邻

最简单却最直觉的机器学习算法：没有训练，只有记忆。通过找出测试点最近的 k 个邻居并投票决定分类——「近朱者赤，近墨者黑」。

历史背景
从问题到突破
1951
Fix & Hodges 提出 k 近邻
Evelyn Fix 和 Joseph Hodges 在美国空军航空生物研究所工作时首次提出该算法，最初用于空军飞行学员的分类问题。
1968
Cover & Hart 给出理论奠基
Thomas Cover 和 Peter Hart 发表《Nearest Neighbor Pattern Classification》，建立了 k-NN 的严格数学框架，证明了两类错误率的界限。
1977
Rost's 经验验证
M. Rost 在大量真实数据集上系统验证了 k-NN 的有效性，推动其成为模式识别领域的标准方法之一。
1990s–至今
高效近似搜索的发展
KD-Tree、Ball-Tree、Locality-Sensitive Hashing (LSH) 等数据结构被引入以加速近邻搜索，使 k-NN 在高维大规模场景下仍具实用价值。

核心思想

近朱者赤，近墨者黑。相似的事物应该有相似的输出。k-NN 不做任何参数学习，只是把训练数据全部「记住」，在预测时找出离测试样本最近的 k 个邻居，通过多数投票决定其类别。这是一种惰性学习（Lazy Learning）——学习成本集中在预测阶段而非训练阶段。

数学原理
距离与预测
欧氏距离（p = 2 的闵可夫斯基特例）
d(x, y) = √( Σᵢ (xᵢ − yᵢ)² )
最常用的默认距离度量，直观反映空间中的直线距离。
曼哈顿距离（p = 1）
d(x, y) = Σᵢ |xᵢ − yᵢ|
网格路径距离，在高维空间通常比欧氏距离更稳定。
闵可夫斯基距离（通用形式）
d(x, y) = ( Σᵢ |xᵢ − yᵢ|ᵖ )¹⁄ᵖ
p = 1 退化为曼哈顿距离，p = 2 退化为欧氏距离，p → ∞ 退化为切比雪夫距离。
预测规则：多数投票
ŷ = argmax_c Σᵢ₌₁ᵏ I(yᵢ = c)
N_k(x) 表示训练集中离 x 最近的 k 个邻居的集合；I(·) 为指示函数，统计 k 个邻居中各类别的票数，取票数最多的类别。
代码实现
从零实现 k-NN
Python · knn.py 
import numpy as np

class KNNClassifier:
    """k 近邻分类器（惰性学习）"""
    
    def __init__(self, k=3, metric='euclidean'):
        self.k = k
        self.metric = metric
        self.X_train = None
        self.y_train = None
    
    def fit(self, X, y):
        # k-NN 无需训练，直接存储数据
        self.X_train = np.asarray(X)
        self.y_train = np.asarray(y)
        return self
    
    def _distance(self, x1, x2):
        if self.metric == 'euclidean':
            return np.sqrt(np.sum((x1 - x2) ** 2))
        elif self.metric == 'manhattan':
            return np.sum(np.abs(x1 - x2))
        else:
            return np.sqrt(np.sum((x1 - x2) ** 2))
    
    def predict(self, X_test):
        predictions = []
        for x in X_test:
            # 计算与所有训练点的距离
            dists = [self._distance(x, xt) for xt in self.X_train]
            # 取最近 k 个邻居的索引
            knn_idx = np.argsort(dists)[:self.k]
            # 多数投票
            knn_labels = self.y_train[knn_idx]
            pred = np.bincount(knn_labels).argmax()
            predictions.append(pred)
        return np.array(predictions)
局限与洞察
当 k-NN 遇到现实

⚠ 主要局限

计算成本高：每次预测需计算与所有训练样本的距离，O(n) 复杂度在大数据集上代价巨大。

维度灾难：高维空间中所有点的距离趋于相近，k-NN 的分类能力显著下降。

对噪声敏感：k 值过小（如 k=1）时，异常点会直接误导预测结果。

需要特征缩放：各特征量纲不同时，距离计算会被大尺度特征主导。

💡 经验法则

k 值选择：通常取奇数避免平局；经验公式 k ≈ √n（n 为训练样本数）；通过交叉验证确定最优 k。

距离度量：低维首选欧氏距离；高维或稀疏数据推荐曼哈顿距离；闵可夫斯基距离可作为统一框架。

加速手段：KD-Tree / Ball-Tree 在低维有效；LSH 在高维近似搜索中表现出色。

预处理：务必做标准化（StandardScaler）或归一化（Min-Max），否则距离计算失真。

学习心得
关键洞察

学到的知识

  • 没有显式训练过程，直接存储全部训练数据——惰性学习的核心特征
  • k 值选择至关重要：太小对噪声敏感，太大会平滑决策边界导致欠拟合
  • 距离度量直接影响分类结果，需根据数据特性选择
  • 特征缩放是必须的前置步骤，否则量纲差异会扭曲距离计算
  • 维度灾难是 k-NN 的根本性局限，高维场景下需谨慎使用

思考题答案

  • k 值如何选择？取奇数避免平局；通过交叉验证选择；经验法则 k ≈ √n
  • 距离度量如何选择？欧氏距离是最常用默认；曼哈顿距离在高维更稳定；根据数据分布特性决定
  • 如何解决计算效率问题？使用 KD-Tree / Ball-Tree 降维加速；高维场景采用 LSH 近似搜索
