# 第五阶段：大模型时代（2020-至今）

## 包含模型

1. **Scaling Law** - 缩放定律
   - 描述模型性能与参数规模、数据量的关系
   - Kaplan et al., 2020

2. **Diffusion Model** - 扩散模型
   - 通过逐步去噪生成图像
   - Ho et al., 2020 (DDPM)
   - 启发了Stable Diffusion、DALL-E等

3. **ViT** - Vision Transformer
   - 将Transformer应用于图像识别
   - Dosovitskiy et al., 2020
   - 改变了视觉模型的架构范式

## 核心思想

- **Scaling Law**: 模型性能可以通过简单公式预测
- **Diffusion**: 去噪扩散概率模型
- **ViT**: 纯注意力机制的视觉模型

## 历史影响

- 缩放定律指导了GPT-3、PaLM等大模型的设计
- 扩散模型成为图像生成的主流方法
- ViT开启了视觉Transformer的时代
