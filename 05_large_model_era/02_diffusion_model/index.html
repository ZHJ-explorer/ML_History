扩散模型

去噪扩散概率模型（DDPM）通过逐步添加噪声将数据分布推向高斯噪声，再通过训练神经网络学习逆向去噪过程，从而从纯噪声中生成高质量图像。

历史背景
从问题到突破

Jonathan Ho et al. 在 2020 年提出了去噪扩散概率模型（DDPM），将 Sohl-Dickstein 等人2015年的思想重新包装为可与VAE/GAN竞争的高效生成模型。

核心洞察：与其直接学习复杂的数据分布 p(x)，不如学习一个逐步去噪的过程。前向过程是固定的马尔可夫链，逐步添加高斯噪声；反向过程是用神经网络学习的马尔可夫链，逐步去除噪声。

DDPM 在 ImageNet 上实现了当时生成模型的最佳 FID 分数，开启了扩散模型在图像生成领域的统治时代，后续催生了 Stable Diffusion、DALL-E 2、Midjourney 等革命性作品。

数学原理
核心公式
前向扩散过程（固定马尔可夫链）
q(x_t | x_{t-1}) = N(x_t; √(1-β_t) · x_{t-1}, β_t · I)
q(x_t|x_0) = N(x_t; √ᾱ_t · x_0, (1-ᾱ_t) · I)
β_t 为方差调度（线性/余弦），ᾱ_t = ∏(1-β_i)，可直接从 x₀ 采样任意时刻 t 的噪声版本
反向去噪过程（可学习）
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))
网络 ε_θ 预测添加的噪声，均值重建：μ_θ = (1/√α_t)(x_t - (1-α_t)/√(1-ᾱ_t) · ε_θ(x_t, t))
训练目标（简化 ELBO）
L_simple = E_{x₀, ε, t}[ ||ε - ε_θ(x_t, t)||² ]
在随机时间步 t 和随机噪声 ε 上取期望，训练网络预测真实添加的噪声
采样流程（反向递推）
for t = T, T-1, ..., 1:
  z = 若 t>1 则 N(0,I) 否则无
  x_{t-1} = (1/√α_t)(x_t - (1-α_t)/√(1-ᾱ_t) · ε_θ(x_t, t)) + σ_t · z
从纯高斯噪声 x_T ~ N(0,I) 出发，迭代 T 步去噪得到生成样本 x₀

class SinusoidalPositionEmbeddings(nn.Module):
    def forward(self, x):
        half_dim = self.dim // 2
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim) * -emb)
        emb = x.unsqueeze(-1) * emb.unsqueeze(0)
        return torch.cat((emb.sin(), emb.cos()), dim=-1)

class ResBlock(nn.Module):
    def forward(self, x, t):
        emb = self.scale_emb(t.float())
        h = self.net(x) * (1 + emb) + emb
        return x + h   # 残差连接

学习心得
关键洞察

学到的知识

  • 扩散模型的核心思想：将复杂的数据分布通过逐步加噪转化为简单的高斯分布，再学习逆向去噪过程
  • 前向过程是固定的马尔可夫链（无需学习），反向过程用神经网络参数化（需要训练）
  • 余弦噪声调度比线性调度更平滑，能显著提升生成质量
  • 训练目标极简：直接让网络预测添加的噪声，等价于最大化数据的下界（ELBO）
  • 采样需要 T 步迭代（通常 1000 步），计算成本是主要瓶颈，后续有 DDIM 等加速方法

踩坑记录

  • 扩散模型采样需要很多步（100-1000），计算成本远高于 GAN/VQGAN
  • 噪声调度 β_t 的选择对生成质量影响很大，余弦调度表现最佳
  • 时间步 t 的位置编码需要用正弦函数而非简单线性映射，才能捕捉周期性
