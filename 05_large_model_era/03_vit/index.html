历史背景
从问题到突破

Dosovitskiy et al. 在 2020 年提出了 ViT（Vision Transformer），这是机器学习发展史上的一个重要里程碑。

在此之前，CNN 一直是视觉任务的绝对主导。ViT 的突破性在于：它证明了当使用足够大规模的数据和算力进行预训练时，纯 Transformer 架构可以超越专门设计的 CNN。

核心思想是将图像切割为固定大小的 Patch（图块），每个 Patch 视为一个「词」，然后通过标准 Transformer 编码器处理。这种方法直接移植了 NLP 中成功的 Transformer 架构到视觉领域。

数学原理
核心公式
Patch Embedding 线性投影
x_emb = Flatten(Patchi) · Wproj
将每个 h×w 的图像块展平后，通过线性层映射到 d 维嵌入空间
多头自注意力 (Multi-Head Self-Attention)
Attention(Q, K, V) = softmax(QKT / √dk) · V
Q/K/V 分别来自输入的不同线性变换；多头并行计算后拼接
位置编码 (Positional Encoding)
x'i = xi + pos_embedi
可学习的位置编码，让模型感知 Patch 的原始空间位置
前向传播流程
x = PatchEmbed(ximg)
x = [CLS; x]
x = x + pos_embed
for layer in layers:
  x = x + MHA(Norm(x))
  x = x + MLP(Norm(x))
output = Head(Norm(x[:, 0]))
CLS token 经过所有层后聚合全局信息，最终通过分类头输出

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, embed_dim=768):
        super().__span class="fn">init__()
        self.proj = nn.Conv2d(3, embed_dim, kernel_size=patch_size, stride=patch_size)
    
    def forward(self, x):
        x = self.proj(x)          # (B, 768, 14, 14)
        x = x.flatten(2)         # (B, 768, 196)
        x = x.transpose(1, 2)    # (B, 196, 768)
        return x

class ViT(nn.Module):
    def __init__(self, ...):
        self.patch_embed = PatchEmbedding(...)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, 197, embed_dim))
        self.layers = nn.ModuleList([...]) # 12 层 Transformer
    
    def forward(self, x):
        x = self.patch_embed(x)
        cls = self.cls_token.expand(x.shape[0], -1, -1)
        x = torch.cat((cls, x), dim=1)
        x = x + self.pos_embed
        for layer in self.layers:
            x = x + layer['attn'](layer['norm1'](x))
            x = x + layer['mlp'](layer['norm2'](x))
        return self.head(self.norm(x)[:, 0])

学习心得
关键洞察

学到的知识

  • ViT 将图像切成固定大小的 Patch，每个 Patch 视为序列中的一个 token
  • CNN 依赖局部感受野，而 Transformer 通过全局注意力捕捉长距离依赖
  • ViT 需要大量数据预训练才能发挥优势（小规模数据上 CNN 更好）
  • CLS token 作为图像级别的摘要，最终用于分类输出
  • 位置编码让模型感知 Patch 的空间排列顺序

踩坑记录

  • ViT 在小数据集上容易过拟合，需要数据增强或迁移学习
  • Patch 大小选择很重要：太大丢失细节，太小计算成本高
  • 训练时需要足够大的 batch size 才能保证稳定性
