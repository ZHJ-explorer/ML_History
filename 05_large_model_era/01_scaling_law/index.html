缩放定律

Kaplan et al. (2020) 发现：深度学习模型的性能与参数规模、数据量之间存在简单的幂律关系。这一发现指导了GPT-3、PaLM等超大模型的设计。

核心思想
性能可预测的幂律关系

缩放定律指出，深度学习模型的性能（通常用损失函数L衡量）与参数量N和数据量D之间存在简单的幂律关系：

核心公式
L(N, D) = a · N-α + b · D-β + L∞
其中 a, α, b, β, L∞ 为拟合参数。这意味着通过增加参数和数据，可以 predictable 地提升模型性能。

这一发现的意义在于：在训练更大模型之前，就可以预测需要多少参数和数据才能达到目标性能。这极大地降低了大模型设计的试错成本。

class ScalingLaw:
    """缩放定律：预测模型性能与参数规模的关系"""
    
    def __init__(self):
        self.a = None
        self.alpha = None
        self.L_infinity = None
    
    def fit(self, N, L):
        # 对数变换后线性拟合
        log_N = np.log(N)
        log_L = np.log(L - np.min(L) + 1e-10)
        coeffs = np.polyfit(log_N, log_L, 1)
        self.alpha = -coeffs[0]
        self.a = np.exp(coeffs[1])
        self.L_infinity = np.min(L) * 0.5
    
    def predict(self, N):
        return self.a * N**(-self.alpha) + self.L_infinity
学习心得
关键洞察

学到的知识

  • 缩放定律揭示了模型性能与参数规模的简单幂律关系
  • 可以通过小规模实验预测大模型性能，大幅降低试错成本
  • 参数和数据应该按特定比例增加才能获得最佳效率

思考题答案

  • 为什么大模型需要更多数据？ - 缩放定律表明 L ~ N^(-α) * D^(-β)，参数和数据都需要增加
  • 缩放定律的局限性？ - 在极端规模下可能出现饱和或突变
