缩放定律

Kaplan 等人发现，深度学习模型的性能与参数量、数据量之间存在简洁的幂律关系——参数每增加10倍，损失约减少25%。这一发现直接指导了 GPT-3、PaLM 等巨型语言模型的设计。

数学原理
核心公式
缩放定律（参数缩放）
L(N) = a · N−α + L∞
L: 损失（验证集交叉熵）；N: 参数量；a, α, L∞ 为拟合常数。α ≈ 0.076 意味着参数量每增加 10 倍，损失约下降 25%。
数据缩放定律
L(D) = b · D−β + L∞
D: 训练数据量；β ≈ 0.095。数据增长带来的收益略大于参数增长（β > α）。
Chinchia 定律（计算最优配比）
N / D ≈ constant  →  N ≈ 0.0275 · C,   D ≈ 0.293 · C
C 为总计算预算（FLOPs）。参数和数据应等比例缩放，否则模型处于欠训练或过训练状态。
综合缩放公式
L(N, D) = a · N−α + b · D−β + L∞
联合考虑参数和数据两个维度，Loss 可同时从两方面优化。当 N, D → ∞ 时，L → L∞（不可约下界）。
代码实现
Python 核心逻辑
Python · model.py 
import numpy as np

class ScalingLaw:
    """缩放定律：L(N) = a * N^(-alpha) + L_inf"""
    
    def __init__(self):
        self.a = None
        self.alpha = None
        self.L_inf = None
    
    def fit(self, N, L):
        # 对数空间线性回归
        log_N = np.log(N)
        log_L = np.log(L - np.min(L) + 1e-10)
        coeffs = np.polyfit(log_N, log_L, 1)
        self.alpha = -coeffs[0]
        self.a = np.exp(coeffs[1])
        self.L_inf = np.min(L) * 0.5
        return self
    
    def predict(self, N):
        return self.a * N**(-self.alpha) + self.L_inf
    
    def optimal_n_params(self, target_loss, max_n=1e12):
        if target_loss <= self.L_inf:
            return max_n
        return (self.a / (target_loss - self.L_inf))**(/1/self.alpha)

# 使用示例
law = ScalingLaw()
N = np.logspace(6, 9, 20)       # 1M ~ 1B 参数
L = 1.0 * N**(-0.25) + 0.1
law.fit(N, L)
print(f"α = {law.alpha:.4f}, L_inf = {law.L_inf:.4f}")
print(law.predict(175e9))     # GPT-3 参数量预测

学习心得
关键洞察

学到的知识

  • 缩放定律揭示了模型性能与参数规模之间的幂律关系：L(N) = a·N−α + L∞
  • 在双对数坐标下，这条曲线是一条直线，斜率为 −α（约 −0.076）
  • Chinchia 定律进一步指出：给定计算预算，参数和数据应等比例缩放才能达到最优效率
  • 缩放定律直接指导了 GPT-3（175B）、PaLM（540B）等模型的规模设计

关键洞察

  • 参数量每增加 10 倍，Loss 约下降 25%（α ≈ 0.076）
  • L∞ 是理论下界——即使无限增加参数，Loss 也不会低于此值，代表任务本身的难度极限
  • GPT-3 训练时数据不足（被 Chinchia 定律指出），后续模型已通过增加数据量来弥补
  • 缩放定律的普适性极强：不仅适用于语言模型，也适用于图像模型（ViT）、多模态模型等

与前后模型的关联

  • 承前：Transformer 架构（2017）提供了可扩展的基础设施，使大规模训练成为可能
  • 启后：ViT（视觉 Transformer）和扩散模型同样受益于缩放定律的洞察——更大模型 + 更多数据 = 更好性能
  • 后续发展：Chinchia-optimal 训练策略、MoE（混合专家）架构、更高效的预训练目标
