历史背景
从问题到突破

Hochreiter & Schmidhuber 在 1997 年提出了 LSTM，这是机器学习发展史上的一个重要里程碑。

传统RNN难以学习长序列依赖，梯度消失导致早期输入信息丢失，训练深层RNN困难。

1997
LSTM提出
Hochreiter & Schmidhuber 发表论文 "Long Short-Term Memory"，引入门控机制
核心突破
三个门控 + 细胞状态
遗忘门、输入门、输出门控制信息流动，细胞状态作为信息高速公路
影响
开启序列建模新时代
应用于机器翻译、语音识别，启发Transformer发展
数学原理
核心公式
遗忘门
ft = σ(Wfxt + Ufht-1 + bf)
决定丢弃多少历史信息，值域 (0, 1)
输入门
it = σ(Wixt + Uiht-1 + bi)
决定更新多少新信息
输出门
ot = σ(Woxt + Uoht-1 + bo)
决定输出多少当前信息
候选细胞状态
C̃t = tanh(Wcxt + Ucht-1 + bc)
生成候选更新值
细胞状态更新
Ct = ft ⊙ Ct-1 + it ⊙ C̃t
旧状态 × 遗忘门 + 新信息 × 输入门
隐藏状态输出
ht = ot ⊙ tanh(Ct)
细胞状态经过 tanh 后由输出门控制

class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__span class="fn">init__()
        # 四个权重矩阵
        self.W_f = nn.Parameter(torch.randn(hidden_size, input_size) * 0.01)
        self.W_i = nn.Parameter(torch.randn(hidden_size, input_size) * 0.01)
        self.W_o = nn.Parameter(torch.randn(hidden_size, input_size) * 0.01)
        self.W_c = nn.Parameter(torch.randn(hidden_size, input_size) * 0.01)
        
    def forward(self, x, h_prev, c_prev):
        # 三个门 + 候选状态
        f = torch.sigmoid(x @ self.W_f.T + h_prev @ self.U_f.T + self.b_f)
        i = torch.sigmoid(x @ self.W_i.T + h_prev @ self.U_i.T + self.b_i)
        o = torch.sigmoid(x @ self.W_o.T + h_prev @ self.U_o.T + self.b_o)
        c_tilda = torch.tanh(x @ self.W_c.T + h_prev @ self.U_c.T + self.b_c)
        
        # 细胞状态与隐藏状态更新
        c_t = f * c_prev + i * c_tilda
        h_t = o * torch.tanh(c_t)
        return h_t, c_t
局限与影响
历史评价

计算局限

• 计算复杂度高
• 参数较多
• 后被GRU等简化版本部分取代

历史影响

• 开启序列建模新时代
• 应用于机器翻译、语音识别
• 启发了Transformer的发展

学习心得
关键洞察

学到的知识

  • LSTM通过门控机制控制信息流动
  • 细胞状态是LSTM的核心创新
  • 三个门分别控制遗忘、输入和输出

踩坑记录

  • 初始化的隐藏状态需要匹配 batch size
  • 多层LSTM需要正确处理层间连接

思考题答案

  • 为什么能解决梯度消失？ 细胞状态提供了梯度流动的"高速公路"，门控机制避免了梯度的连乘消失
  • GRU和LSTM的区别？ GRU将遗忘门和输入门合并为更新门，参数更少，计算更快
  • LSTM在现代NLP中的角色？ Transformer出现前是主流，现在仍用于某些序列建模任务
