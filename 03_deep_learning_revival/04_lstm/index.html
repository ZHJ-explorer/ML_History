从问题到突破

1997年，Hochreiter和Schmidhuber提出了LSTM（Long Short-Term Memory）网络，解决了传统RNN的梯度消失问题。LSTM通过引入门控机制，能够学习长期依赖关系。

**当时的问题**：

  • → 传统RNN难以学习长序列依赖
  • → 梯度消失导致早期输入信息丢失
  • → 训练深层RNN困难

    • **核心突破**：

  • → 遗忘门、输入门、输出门三个门控机制
  • → 细胞状态作为信息高速公路

        f_t = sigmoid(W_xf * x_t + W_hf * h_{t-1} + b_f)  # 遗忘门
        i_t = sigmoid(W_xi * x_t + W_hi * h_{t-1} + b_i)  # 输入门
        o_t = sigmoid(W_xo * x_t + W_ho * h_{t-1} + b_o)  # 输出门
        C_tilda = tanh(W_xc * x_t + W_hc * h_{t-1} + b_c) # 候选细胞
        C_t = f_t * C_{t-1} + i_t * C_tilda                # 细胞状态
        h_t = o_t * tanh(C_t)                              # 隐藏状态

        X, y = [], []
        for i in range(len(data) - seq_length):

    学到的知识

      1. LSTM通过门控机制控制信息流动

      2. 细胞状态是LSTM的核心创新

      3. 三个门分别控制遗忘、输入和输出

    思考题答案

      1. **LSTM为什么能解决梯度消失问题？**

    • → 细胞状态提供了梯度流动的"高速公路"
    • → 门控机制避免了梯度的连乘消失

      • 2. **GRU和LSTM有什么区别？**

    • → GRU将遗忘门和输入门合并为更新门
    • → GRU参数更少，计算更快
    • → 性能上两者相差不大

      • 3. **LSTM在现代NLP中的角色是什么？**

    • → 在Transformer出现前是主流方法
    • → 现在仍用于某些序列建模任务
    • → 理解LSTM有助于理解Transformer
