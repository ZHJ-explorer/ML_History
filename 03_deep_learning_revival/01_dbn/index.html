数学原理
核心公式
RBM 能量函数
E(v, h) = −Σᵢ aᵢvᵢ − Σⱼ bⱼhⱼ − Σᵢⱼ vᵢwᵢⱼhⱼ
v 为可见层状态，h 为隐藏层状态，a/b 为偏置，w 为连接权重
条件概率分布
P(hⱼ=1|v) = σ(bⱼ + Σᵢ wᵢⱼvᵢ)
P(vᵢ=1|h) = σ(aᵢ + Σⱼ wᵢⱼhⱼ)
σ 为 sigmoid 函数，条件独立性是 RBM 的核心假设
对比散度（CD-k）更新规则
Δwᵢⱼ = ε · (⟨vᵢhⱼ⟩data − ⟨vᵢhⱼ⟩recon)
Δaᵢ = ε · (⟨vᵢ⟩data − ⟨vᵢ⟩recon)
Δbⱼ = ε · (⟨hⱼ⟩data − ⟨hⱼ⟩recon)
CD-1 仅需一步 Gibbs 采样近似梯度，ε 为学习率
DBN 训练流程
1. 逐层预训练：对每个 RBM 执行 CD-k 无监督训练
2. 构建 DBN：将所有预训练 RBM 堆叠
3. 有监督微调：使用反向传播在全网络上进行梯度下降
预训练提供好的初始化权重，微调实现端到端优化

import numpy as np

class RBM:
    """受限玻尔兹曼机 (Restricted Boltzmann Machine)"""
    def __init__(self, n_visible, n_hidden):
        self.n_visible = n_visible
        self.n_hidden = n_hidden
        self.w = np.random.randn(n_visible, n_hidden) * 0.01
        self.a = np.zeros(n_visible)
        self.b = np.zeros(n_hidden)

    def sample_h(self, v):
        z = v @ self.w + self.b
        return 1 / (1 + np.exp(-z))

    def cd1(self, data, lr=0.01):
        # 正相：数据分布
        ph_means = self.sample_h(data)
        ph_nodes = (ph_means > np.random.random(ph_means.shape)).astype(float)

        # 负相：一步 Gibbs 采样
        nv_means = self.sample_v(ph_nodes)
        nh_means = self.sample_h(nv_means)

        # 权重更新
        self.w += lr * (data.T @ ph_means - nv_means.T @ ph_nodes)
        self.a += lr * (data.mean(axis=0) - nv_means.mean(axis=0))
        self.b += lr * (ph_means.mean(axis=0) - nh_means.mean(axis=0))
        return self

class DBN:
    """深度信念网络：多层RBM堆叠 + 微调"""
    def __init__(self, layer_sizes):
        self.rbms = [RBM(layer_sizes[i], layer_sizes[i+1])
                     for i in range(len(layer_sizes)-1)]

    def pretrain(self, data, epochs=50, lr=0.01):
        # 逐层无监督预训练
        current = data
        for rbm in self.rbms:
            for epoch in range(epochs):
                rbm.cd1(current, lr)
            current = rbm.sample_h(current)
        return self

    def forward(self, x):
        # 前向传播：逐层通过所有RBM
        for rbm in self.rbms:
            x = rbm.sample_h(x)
        return x

关键洞察

学到的知识

  • DBN 由多个 RBM 堆叠而成，逐层贪心预训练解决了深层网络训练难题
  • 无监督预训练 + 有监督微调是早期深度学习的核心策略
  • RBM 的 CD-1 算法实现需要仔细处理正负相的能量差
  • 预训练后的微调阶段需要额外实现反向传播

思考题答案

  • 为什么 DBN 需要逐层预训练？ — 避免梯度消失，每层学习数据的层次化特征表示
  • 对比散度（CD）的原理是什么？ — 用 k 步 Gibbs 采样近似梯度，CD-1 用一次采样近似数据分布
  • DBN 与现代深度学习的关系是什么？ — DBN 启发了深度网络的训练方法；现代深度学习更多使用 ReLU+Dropout+BatchNorm
