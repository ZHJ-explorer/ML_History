# 深度信念网络（DBN）

## 历史背景

2006年，Hinton等人发表了"Deep Belief Networks are Universal Learning Machines"，标志着深度学习复兴的开始。DBN由多个受限玻尔兹曼机（RBM）堆叠而成，采用无监督逐层预训练+有监督微调的策略。

**当时的问题**：
- 深层网络难以训练，梯度消失问题严重
- 缺乏有效的无监督预训练方法
- 计算能力逐渐提升

**核心突破**：
- 逐层贪心预训练
- 无监督特征学习

## 数学原理

### 受限玻尔兹曼机（RBM）

能量函数：
$$E(v, h) = -\sum_i a_i v_i - \sum_j b_j h_j - \sum_{i,j} v_i w_{ij} h_j$$

联合概率：
$$P(v, h) = \frac{e^{-E(v,h)}}{Z}$$

条件分布：
$$P(h_j=1|v) = \sigma(b_j + \sum_i w_{ij} v_i)$$
$$P(v_i=1|h) = \sigma(a_i + \sum_j w_{ij} h_j)$$

### DBN训练

1. 逐层预训练：对每个RBM进行对比散度（CD）训练
2. 微调：将所有RBM堆叠，进行有监督的梯度下降

## 历史局限性

1. 计算成本高
2. 后被更高效的方法取代（如ReLU+Dropout）
3. 对超参数敏感

## 历史影响

- 开启了深度学习复兴
- 启发了自编码器、深度残差网络等
