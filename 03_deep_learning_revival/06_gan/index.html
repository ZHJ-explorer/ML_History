历史背景
从问题到突破

Ian Goodfellow 在 2014 年提出了 GAN（Generative Adversarial Networks），开创了生成模型的新范式。GAN 通过生成器和判别器的对抗训练，能够生成逼真的数据。

当时的问题：

  • 传统生成模型（如 VAE）生成的样本模糊
  • 缺乏有效的生成模型训练方法

核心突破：

  • 对抗训练框架 — 无需显式概率密度估计
  • 生成器与判别器博弈优化

数学原理
核心目标函数
极小极大目标函数
min_G max_D V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]
D 最大化区分真假的能力；G 最小化被 D 识别为假的概率

生成器 G

接收随机噪声 z，学习生成逼真样本，目标是「骗过」判别器。梯度方向：让 D(G(z)) 趋近于 1。

判别器 D

接收真实样本 x 或假样本 G(z)，学习输出接近 1（真）或 0（假）。梯度方向：正确区分真假。

PyTorch 核心逻辑

import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, z_dim=100, img_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(z_dim, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, img_dim),
            nn.Tanh()
        )
    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, img_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(img_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )
    def forward(self, x):
        return self.net(x).view(-1)

学习心得
关键洞察

学到的知识

  • GAN 由生成器 G 和判别器 D 两个网络组成
  • 对抗训练是核心思想 — G 生成假样本，D 区分真假
  • 生成器学习生成逼真数据，判别器学习区分真假

踩坑记录

  • 学习率需要仔细调整，太高容易不稳定
  • 生成器和判别器的训练需要平衡，一方太强会导致另一方梯度消失

思考题

  • 为什么 GAN 训练不稳定？ — 生成器和判别器同时优化导致非平稳博弈，梯度消失问题
  • 模式崩溃是什么？如何避免？ — 生成器只生成少数几种样本；避免方法：使用最小二乘 GAN、WGAN 等变体
  • GAN 和 VAE 各有什么优缺点？ — GAN 生成质量高但训练不稳定；VAE 训练稳定但生成样本模糊
