# GAN（生成对抗网络）

## 历史背景

2014年，Goodfellow等人提出了GAN（Generative Adversarial Networks），开创了生成模型的新范式。GAN通过生成器和判别器的对抗训练，能够生成逼真的数据。

**当时的问题**：
- 传统生成模型（如VAE）生成的样本模糊
- 缺乏有效的生成模型训练方法

**核心突破**：
- 对抗训练框架
- 无需显式概率密度估计

## 数学原理

### 目标函数

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

### 训练过程

1. 固定G，训练D最大化区分能力
2. 固定D，训练G最小化被识别的概率

## 历史局限性

1. 训练不稳定
2. 模式崩溃
3. 评估困难

## 历史影响

- 开启了生成模型的新时代
- 应用于图像生成、超分辨率等
- 启发了StyleGAN、Diffusion Model等
