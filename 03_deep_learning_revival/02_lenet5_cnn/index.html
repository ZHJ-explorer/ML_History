数学原理
核心公式
卷积运算
(f * g)[i, j] = Σm Σn f[m, n] · g[i−m, j−n]
二维卷积：输入在卷积核的局部窗口内进行加权求和。对应代码 ManualConv2D.forward()
平均池化
output[i, j] = (1/k²) Σm,n input[i·s + m, j·s + n]
对 k×k 窗口内元素取均值进行降采样。对应代码 ManualAvgPool2D.forward()
网络层尺寸变换
Out = ⌊(In + 2·pad − k) / stride⌋ + 1
LeNet-5 中 conv 均用 pad=2，pool 用 stride=2。输入 28→Conv→28→Pool→14→Conv→14→Pool→7

class ManualConv2D(nn.Module):
    def __init__(self, in_ch, out_ch, k, stride=1, pad=0):
        super().__span class="fn">init__()
        self.weight = nn.Parameter(torch.randn(out_ch, in_ch, k, k) * 0.01)
        self.bias = nn.Parameter(torch.zeros(out_ch))

    def forward(self, x):
        # im2col + 矩阵乘法，等价于逐位置卷积
        cols = []
        for i in range(out_h):
            for j in range(out_w):
                h_s, h_e = i*s, i*s+k
                w_s, w_e = j*s, j*s+k
                cols.append(x[:, :, h_s:h_e, w_s:w_e].reshape(B, C*k*k))
        return (torch.matmul(cols, self.weight.reshape(out_ch,-1).t())
                + self.bias).reshape(B, out_ch, out_h, out_w)

# ── LeNet-5 forward ──
x = self.conv1(x)   Conv1: 1→6  # (B, 6, 28, 28)
x = torch.relu(x)
x = self.pool(x)    Pool1: 2×2 # (B, 6, 14, 14)
x = self.conv2(x)   Conv2: 6→16 # (B, 16, 14, 14)
x = torch.relu(x)
x = self.pool(x)    Pool2: 2×2 # (B, 16, 7, 7)
x = x.view(x.size(0), -1)  # (B, 784)
x = torch.relu(self.fc1(x)) FC1: 784→120
x = torch.relu(self.fc2(x)) FC2: 120→84
x = self.fc3(x)     FC3: 84→10

学习心得
关键洞察

学到的知识

  • 卷积层实现：手动遍历每个输出位置，对输入进行局部加权求和
  • 池化层实现：对窗口内元素取平均值进行降采样
  • 卷积的关键是权值共享，大大减少了参数量
  • 池化层增加了模型的平移不变性

踩坑记录

  • 手动卷积时要注意边界处理（padding 和 stride）
  • MNIST 原始图像是 28×28，LeNet-5 设计输入是 32×32，需要填充
  • 训练时收敛较慢，可能需要调整学习率

思考题答案

  • 为什么卷积层需要权值共享？ — 大幅减少参数量，保持空间局部性，增强泛化能力
  • 池化层的作用是什么？ — 降低特征图空间维度，提供平移不变性，防止过拟合
  • LeNet-5 与现代 ResNet 有什么本质区别？ — 深度不同（7层 vs 152+层）、激活函数（sigmoid vs ReLU）、训练方法（SGD vs Adam+BN）、残差连接
