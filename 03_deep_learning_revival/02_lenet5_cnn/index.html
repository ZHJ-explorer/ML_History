    学到的知识

      1. 卷积层实现：手动遍历每个输出位置，对输入进行局部加权求和

      2. 池化层实现：对窗口内元素取平均值进行降采样

      3. 卷积的关键是权值共享，大大减少了参数量

      4. 池化层增加了模型的平移不变性

    思考题答案

      1. **为什么卷积层需要权值共享？**

    • → 大幅减少参数量
    • → 保持空间局部性
    • → 增强模型的泛化能力

      • 2. **池化层的作用是什么？**

    • → 降低特征图空间维度
    • → 提供平移不变性
    • → 防止过拟合

      • 3. **LeNet-5与现代ResNet有什么本质区别？**

    • → 深度不同：LeNet-5只有7层，ResNet可达152+层
    • → 激活函数：LeNet-5用sigmoid/tanh，现代用ReLU
    • → 训练方法：LeNet-5用SGD，现代用Adam+BatchNorm
    • → 残差连接：ResNet引入了skip connection解决梯度消失
