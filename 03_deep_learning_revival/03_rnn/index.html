时间展开结构
RNN 在时间维度上展开为重复的网络层，每个时间步共享同一组权重。隐藏状态 h 在时间步之间传递，保留历史信息。

数学原理
核心公式
隐藏状态更新
ht = tanh( Wxh · xt + Whh · ht-1 + bh )
Wxh: 输入→隐藏权重  ·  Whh: 隐藏→隐藏权重  ·  bh: 偏置
输出计算
yt = Why · ht + by
Why: 隐藏→输出权重  ·  每个时间步独立计算输出

核心问题：梯度消失

长序列反向传播时梯度指数衰减：
∂L/∂W_hh ∝ (W_hh)T·...·(W_hh)T
早期输入信息难以传递到后期。

解决方案

• LSTM：引入输入/遗忘/输出门
• GRU：简化门控机制
• 梯度裁剪：限制梯度范数

代码实现
ManualRNNCell 核心逻辑
Python · model.py 
class ManualRNNCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.w_xh = nn.Parameter(torch.randn(input_size, hidden_size) * 0.01)
        self.w_hh = nn.Parameter(torch.randn(hidden_size, hidden_size) * 0.01)
        self.b_h  = nn.Parameter(torch.zeros(hidden_size))

    def forward(self, x_t, h_prev):
        # h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)
        h_t = torch.tanh(
            torch.matmul(x_t, self.w_xh) +
            torch.matmul(h_prev, self.w_hh) +
            self.b_h
        )
        return h_t

学习心得
关键洞察

学到的知识

  • RNN 通过隐藏状态实现序列记忆，每个时间步共享相同权重
  • 手动实现 RNN 单元有助于理解内部计算机制
  • 梯度消失是 RNN 的主要瓶颈，长序列上效果不佳
  • LSTM/GRU 通过门控机制解决了梯度消失问题

踩坑记录

  • RNN 训练时容易出现梯度爆炸，需要梯度裁剪
  • 序列长度影响训练效率，过长会导致内存不足
  • 简单 RNN 在长序列上效果不佳，需要 LSTM/GRU

思考题答案

  • RNN 和 MLP 的本质区别？ RNN 有隐藏状态能记住历史信息，权重共享可处理任意长度输入；MLP 每个输入独立处理
  • 为什么 RNN 出现梯度消失？ 反向传播跨越多个时间步，权重矩阵连乘导致梯度指数衰减，tanh 导数小于 1 加剧此问题
  • LSTM 相比 RNN 做了什么改进？ 引入输入/遗忘/输出门控，细胞状态独立传递长期信息，有效解决梯度消失
