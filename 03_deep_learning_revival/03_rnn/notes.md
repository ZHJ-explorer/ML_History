# RNN 学习心得

## 学到的知识

1. RNN通过隐藏状态实现序列记忆
2. 每个时间步共享相同的权重
3. 手动实现RNN单元有助于理解其内部机制
4. 梯度消失是RNN的主要瓶颈

## 踩坑记录

- RNN训练时容易出现梯度爆炸，需要梯度裁剪
- 序列长度影响训练效率，过长会导致内存不足
- 简单RNN在长序列上效果不佳，需要LSTM/GRU

## 思考题答案

1. **RNN和MLP的本质区别是什么？**
   - RNN有隐藏状态，能记住历史信息
   - RNN权重共享，能处理任意长度输入
   - MLP每个输入独立处理

2. **为什么RNN会出现梯度消失？**
   - 反向传播时梯度需要跨越多个时间步
   - 权重矩阵的连乘导致梯度指数级衰减
   - tanh激活函数的导数小于1

3. **LSTM相比RNN做了什么改进？**
   - 引入门控机制（输入门、遗忘门、输出门）
   - 细胞状态独立传递长期信息
   - 解决了梯度消失问题
