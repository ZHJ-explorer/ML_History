# Word2Vec学习心得

## 学到的知识

1. CBOW通过上下文预测中心词，Skip-gram相反
2. 负采样将多分类问题转化为二分类问题
3. 词向量可以捕捉语义关系（如king - man + woman = queen）

## 踩坑记录

- 词汇表大小和词向量维度需要仔细选择
- 训练数据量对效果影响很大

## 思考题答案

1. **CBOW和Skip-gram各有什么优缺点？**
   - CBOW：训练快，对常见词效果好
   - Skip-gram：对罕见词效果好，能捕捉更多语义关系

2. **负采样为什么能加速训练？**
   - 将K类分类问题转化为K个二分类问题
   - 只需更新少量权重，而非全部参数

3. **Word2Vec和BERT的词向量有什么区别？**
   - Word2Vec：静态词向量，同一个词无论上下文都是同一个向量
   - BERT：上下文词向量，同一个词在不同语境下有不同的表示
