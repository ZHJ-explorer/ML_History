    class CBOW(nn.Module):
    """CBOW模型：通过上下文预测中心词。"""
    
    def __init__(self, vocab_size, embed_size):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_size)
        self.output = nn.Linear(embed_size, vocab_size)
    
    def forward(self, context_indices):
        """前向传播。
        
        Args:
            context_indices: 上下文词索引，shape (batch, context_size)
            
        Returns:
            预测得分，shape (batch, vocab_size)
        """
        embeds = self.embed(context_indices)  # (batch, context_size, embed_size)
        vector = embeds.mean(dim=1)           # (batch, embed_size)
        output = self.output(vector)          # (batch, vocab_size)
        return output

    从实践中学习

    学到的知识

      1. CBOW通过上下文预测中心词，Skip-gram相反

      2. 负采样将多分类问题转化为二分类问题

      3. 词向量可以捕捉语义关系（如king - man + woman = queen）

    思考题答案

      1. **CBOW和Skip-gram各有什么优缺点？**

    • → CBOW：训练快，对常见词效果好
    • → Skip-gram：对罕见词效果好，能捕捉更多语义关系

      • 2. **负采样为什么能加速训练？**

    • → 将K类分类问题转化为K个二分类问题
    • → 只需更新少量权重，而非全部参数

      • 3. **Word2Vec和BERT的词向量有什么区别？**

    • → Word2Vec：静态词向量，同一个词无论上下文都是同一个向量
    • → BERT：上下文词向量，同一个词在不同语境下有不同的表示
