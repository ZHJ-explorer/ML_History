CBOW

给定上下文词，预测中心词。训练速度快，对常见词效果更好。

P(w_t | w_{t-c}...w_{t+c})

Skip-gram

给定中心词，预测上下文词。对罕见词效果更好，能捕捉更多语义关系。

P(w_{t-c}...w_{t+c} | w_t)
历史背景
从问题到突破

Tomas Mikolov 在 2013 年提出了 Word2Vec，这是机器学习发展史上的一个重要里程碑。

传统词表示方法（如 One-hot）存在两个核心问题：

  • 稀疏性：词汇表越大，向量越稀疏，无法捕捉语义关系
  • 计算成本高：传统方法训练速度慢，难以处理大规模语料

核心突破：

  • 负采样（Negative Sampling）：将多分类问题转化为二分类问题，大幅加速训练
  • 层次Softmax：利用哈夫曼树优化输出层计算

Word2Vec 的词向量能够捕捉语义关系，如经典的 king - man + woman ≈ queen。

数学原理
核心公式
Skip-gram 目标函数
max log P(上下文 | 中心词)
= Σ log σ(v'_w_O · v_w_I)
最大化中心词与上下文词向量点积的对数概率
负采样损失函数
L = -[log σ(v'_w_O · v_w_I)
    + Σ log σ(-v'_w_i · v_w_I)]
1个正样本 + k个负样本（随机采样）
代码实现
PyTorch 核心逻辑
Python · word2vec.py 
import torch
import torch.nn as nn
import torch.nn.functional as F

class Word2Vec(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super().__span class="fn">init__()
        # 输入词向量矩阵
        self.input_embeddings = nn.Embedding(vocab_size, embed_dim)
        # 输出词向量矩阵
        self.output_embeddings = nn.Embedding(vocab_size, embed_dim)
        
    def forward(self, center_words, context_words, negative_samples):
        # 获取词向量
        center_vec = self.input_embeddings(center_words)      # [batch, embed_dim]
        context_vec = self.output_embeddings(context_words)   # [batch, embed_dim]
        neg_vec = self.output_embeddings(negative_samples)    # [batch, K, embed_dim]
        
        # 正样本得分
        pos_score = torch.sum(center_vec * context_vec, dim=-1)  # [batch]
        
        # 负样本得分
        neg_score = torch.bmm(neg_vec, center_vec.unsqueeze(-1)).squeeze(-1)  # [batch, K]
        
        # 负采样损失
        pos_loss = -F.logsigmoid(pos_score)           # -log σ(pos_score)
        neg_loss = -F.logsigmoid(-neg_score).sum(dim=-1)  # -Σ log σ(-neg_score)
        
        return (pos_loss + neg_loss).mean()

学习心得
关键洞察

学到的知识

  • CBOW通过上下文预测中心词，Skip-gram相反
  • 负采样将多分类问题转化为二分类问题，大幅加速训练
  • 词向量可以捕捉语义关系（如 king - man + woman = queen）

踩坑记录

  • 词汇表大小和词向量维度需要仔细选择
  • 训练数据量对效果影响很大

思考题答案

  • CBOW vs Skip-gram：CBOW训练快，对常见词效果好；Skip-gram对罕见词效果好，能捕捉更多语义关系
  • 负采样加速原因：将K类分类转化为K个二分类，只需更新少量权重
  • Word2Vec vs BERT：Word2Vec是静态词向量（同一词同一向量），BERT是上下文词向量（同一词不同语境不同向量）
