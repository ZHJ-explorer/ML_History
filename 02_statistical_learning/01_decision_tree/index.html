历史背景
从问题到突破

Hunt等人在1960年代提出了概念学习系统（CLS），奠定了决策树的基础。当时神经网络处于研究低谷期（感知机寒冬），学界需要可解释的机器学习方法。

1970年代，Quinlan开发了ID3算法，首次引入信息增益作为分裂标准，解决了特征选择的核心问题。1993年，Quinlan进一步提出C4.5算法，改进了ID3的局限性，支持连续值和缺失值处理。

数学原理
核心公式
信息熵 · Information Entropy
H(S) = − Σi=1c pi · log2(pi)
衡量数据集 S 的纯度；熵越低，纯度越高。当所有样本属于同一类时 H(S)=0。
信息增益 · Information Gain
Gain(S, A) = H(S) − Σv∈Values(A) (|Sv| / |S|) · H(Sv)
选择信息增益最大的特征进行分裂；增益越大，分裂后纯度提升越明显。
增益率 · Gain Ratio (C4.5)
GainRatio(S, A) = Gain(S, A) / SplitInfo(S, A)
SplitInfo 惩罚取值较多的特征，解决 ID3 偏向多值特征的缺陷。
代码实现

import numpy as np
from math import log2

class DecisionTree:
    def __init__(self, max_depth=None, min_samples=2):
        self.max_depth = max_depth
        self.min_samples = min_samples
        self.tree = None

    def entropy(self, y):
        """计算信息熵"""
        if len(y) == 0: return 0
        counts = np.bincount(y)
        probs = counts / len(y)
        return -np.sum(probs * np.log2(probs + 1e-12))

    def information_gain(self, y, y_left, y_right):
        """计算信息增益"""
        n, n_l, n_r = len(y), len(y_left), len(y_right)
        if n_l == 0 or n_r == 0: return 0
        parent_entropy = self.entropy(y)
        child_entropy = (n_l / n) * self.entropy(y_left) + (n_r / n) * self.entropy(y_right)
        return parent_entropy - child_entropy

    def fit(self, X, y):
        """递归构建决策树"""
        self.tree = self._build_tree(X, y, depth=0)

    def _build_tree(self, X, y, depth):
        n_samples, n_features = X.shape
        # 停止条件：达到最大深度或节点纯度足够
        if depth >= self.max_depth or np.all(y == y[0]) or n_samples < self.min_samples:
            return {"leaf": True, "prediction": np.bincount(y).argmax()}

        # 寻找最优分裂特征和阈值
        best_gain, best_feature, best_threshold = 0, None, None
        for feature in range(n_features):
            thresholds = np.unique(X[:, feature])
            for threshold in thresholds:
                left_mask = X[:, feature] <= threshold
                gain = self.information_gain(y, y[left_mask], y[~left_mask])
                if gain > best_gain:
                    best_gain, best_feature, best_threshold = gain, feature, threshold

        if best_feature is None:
            return {"leaf": True, "prediction": np.bincount(y).argmax()}

        left_mask = X[:, best_feature] <= best_threshold
        return {
            "leaf": False,
            "feature": best_feature,
            "threshold": best_threshold,
            "gain": best_gain,
            "left": self._build_tree(X[left_mask], y[left_mask], depth + 1),
            "right": self._build_tree(X[~left_mask], y[~left_mask], depth + 1),
        }

算法对比
ID3 vs C4.5 vs CART

ID3 (1986)

使用信息增益作为分裂标准；只能处理离散特征；偏向选择取值较多的特征；不支持缺失值。

C4.5 (1993)

引入增益率解决多值偏向问题；支持连续特征和缺失值；使用剪枝防止过拟合。

CART (1984)

使用基尼不纯度作为分裂标准；构建二叉树；同时支持分类和回归任务。

现代应用

决策树是随机森林和梯度提升树（XGBoost/LightGBM）的基础组件，仍是可解释性场景的首选。

学习心得
关键洞察

学到的知识

  • 信息熵衡量数据集的纯度——熵越低，类别越纯
  • 信息增益选择最优分裂特征——增益越大，纯度提升越明显
  • 最大深度控制树的复杂度——防止过拟合的核心手段
  • 增益率通过分裂信息归一化，解决了 ID3 偏向多值特征的问题

踩坑记录

  • ID3 只支持离散特征，实际数据需要扩展到 C4.5 处理连续值
  • 未剪枝的决策树极易过拟合——必须设置 max_depth 或使用剪枝技术
  • 信息增益对取值多的特征有偏向性，应优先使用增益率或基尼不纯度

思考题答案

  • 信息增益 vs 增益率：信息增益偏向取值多的特征；增益率通过分裂信息归一化解决此问题
  • 如何防止过拟合：设置最大深度、预剪枝（检查增益是否足够大）、后剪枝（构建后剪掉不必要分支）
  • 决策树 vs 神经网络：决策树可解释性强但易过拟合；神经网络表达能力强但需更多数据和调参
