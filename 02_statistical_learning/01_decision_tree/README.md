# 决策树（ID3/C4.5）

## 历史背景

决策树是最经典的分类算法之一。1960年代，Hunt等人提出了概念学习系统（CLS），奠定了决策树的基础。1970年代，Quinlan开发的ID3算法引入了信息增益作为分裂标准。1993年，Quinlan进一步提出C4.5算法，改进了ID3的局限性。

**当时的问题**：
- 神经网络处于研究低谷期（感知机寒冬）
- 需要可解释的机器学习方法
- 处理连续值和缺失值的能力不足

**核心突破**：
- 信息增益作为分裂标准
- 剪枝技术防止过拟合
- 处理连续值和缺失值

## 数学原理

### 信息熵

$$H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$$

### 信息增益

$$Gain(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$

### 增益率（C4.5）

$$GainRatio(S, A) = \frac{Gain(S, A)}{SplitInfo(S, A)}$$

## 历史局限性

1. 偏向选择取值较多的特征
2. 对噪声敏感
3. 只能处理分类问题（C4.5可扩展到回归）

## 历史影响

- 直接启发了随机森林和梯度提升树
- 仍是可解释性要求场景的首选
