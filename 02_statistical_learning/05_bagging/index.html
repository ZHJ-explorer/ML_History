历史背景
从问题到突破

Leo Breiman 在 1996 年提出了 Bagging，这是机器学习发展史上的一个重要里程碑。

Bagging（Bootstrap Aggregating）由Leo Breiman于1996年提出，核心思想是通过构建多个独立的基学习器并集成它们的预测结果（回归取平均，分类取投票）来提高模型的稳定性和泛化能力。它是集成学习中最经典的方法之一。

Breiman 发现，当基学习器具有较高的方差时（如决策树），Bagging 能显著降低整体误差。其核心洞察是：通过有放回的随机抽样（Bootstrap），每个基学习器看到不同的数据视角，从而获得多样性；而聚合后这种多样性被转化为稳定性。

数学原理
核心公式
Bootstrap 抽样
D_b = {(x_i, y_i)}_{i=1}^n // 从训练集有放回抽取 n 个样本
每个样本被抽中的概率为 1 - (1-1/n)^n ≈ 63.2%，约 36.8% 的样本不会被选中（OOB）
基学习器训练
h_b = Train(D_b), b = 1, 2, ..., B
每个基学习器在各自子集上独立训练，互不影响
集成预测（分类）
ŷ = mode(h₁(x), h₂(x), ..., h_B(x))
多数投票决定最终类别
集成预测（回归）
ŷ = (1/B) × Σ h_b(x)
所有基学习器预测的算术平均
代码实现
model.py 核心逻辑
Python · model.py 
class BaggingClassifier:
    def __init__(self, n_estimators=10, max_samples=1.0):
        self.n_estimators = n_estimators
        self.max_samples = max_samples
        self.classifiers = []

    def fit(self, X, y):
        n_samples = X.shape[0]
        self.classifiers = []
        for _ in range(self.n_estimators):
            # Bootstrap 有放回抽样
            indices = np.random.choice(
                n_samples, 
                int(n_samples * self.max_samples), 
                replace=True
            )
            clf = DecisionTree(max_depth=10)
            clf.fit(X[indices], y[indices])
            self.classifiers.append(clf)
        return self

    def predict(self, X):
        # 收集所有基学习器的预测
        predictions = np.array([
            clf.predict(X) for clf in self.classifiers
        ])
        # 多数投票聚合
        return np.array([
            np.bincount(p).argmax() for p in predictions.T
        ])

OOB (Out-of-Bag) 样本解释

在 Bootstrap 抽样中，每次从 n 个样本中有放回地抽取 n 个样本。每个样本未被抽中的概率为 (1-1/n)^n，当 n 较大时趋近于 1/e ≈ 0.368。

这意味着每次抽样大约有 36.8% 的样本不会被选中，这些样本称为 OOB 样本，可用于验证模型性能而无需额外验证集。

关键特性
Bagging 的特点

✅ 优势

• 有效降低模型方差，提升泛化能力
• 各基学习器可并行训练，效率高
• 无需交叉验证，OOB 即可评估
• 对异常值不敏感

⚠️ 局限性

• 保持偏差不变，仅降低方差
• 基学习器之间完全独立，无信息交换
• 对于低方差模型效果有限
• 模型解释性较差

学习心得
关键洞察

学到的知识

  • Bagging 通过 Bootstrap 有放回抽样产生多样化的子数据集
  • 每个基学习器独立训练，最终通过投票或平均聚合预测结果
  • Bagging 的核心作用是降低模型方差，而不影响偏差
  • OOB 样本约占 36.8%，可作为内置验证集使用
  • 决策树是高方差模型的典型案例，非常适合用 Bagging 改进
  • Random Forest 是在 Bagging 基础上引入特征随机性的改进版本

思考题

  • Bagging 和 Boosting 有什么区别？（Bagging 并行训练、等权聚合；Boosting 串行训练、自适应加权）
  • 为什么 Bagging 可以减少方差而不影响偏差？（每个基学习器偏差相同，平均后偏差不变，但方差降低为原来的 1/B）
  • OOB 错误估计的原理是什么？（利用未参与训练的 OOB 样本评估每个基学习器，平均得到无偏估计）
