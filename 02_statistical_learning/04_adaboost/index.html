Boosting 迭代过程

AdaBoost（Adaptive Boosting）通过多轮迭代训练弱分类器，每轮根据上一轮的预测结果调整样本权重。错误分类的样本权重增加，正确分类的权重减少，使得后续分类器更加关注难分样本。

从问题到突破

Freund & Schapire 在 1995 年提出了 AdaBoost，这是机器学习发展史上的一个重要里程碑。

1995年，Schapire和Freund提出了AdaBoost算法，这是第一个实用的boosting算法。它通过迭代地训练弱分类器并调整样本权重，将多个弱分类器组合成一个强分类器。

自适应权重 指数误差上界 集成学习
数学原理
核心公式
弱分类器加权输出
G_m(x) = sign(Σ α_m · G_m(x))
最终分类器由所有弱分类器的加权投票决定，α_m 为第 m 个分类器的权重系数
系数计算
α_m = ½ · log((1 - e_m) / e_m)
e_m 为第 m 轮分类器的加权错误率，错误率越低，权重越大
样本权重更新
w_{i,m+1} = w_{i,m} · exp(-α_m · y_i · G_m(x_i))
被错误分类的样本权重增大，正确分类的权重减小，使得后续分类器关注困难样本
对比分析
Boosting vs Bagging

Boosting (AdaBoost)

• 串行训练，每轮依赖上一轮结果
• 自适应调整样本权重
• 关注难分样本
• 误差上界指数衰减
• 对异常值敏感

Bagging

• 并行训练，各轮独立
• 均匀采样，权重不变
• 关注整体分布
• 降低方差，减少过拟合
• 对异常值鲁棒

代码实现
Python 核心逻辑
Python · adaboost.py 
import numpy as np
from sklearn.tree import DecisionTreeClassifier

class AdaBoost:
    def __init__(self, n_estimators=10):
        self.n_estimators = n_estimators
        self.classifiers = []
        self.alphas = []
        
    def fit(self, X, y):
        n_samples = X.shape[0]
        weights = np.ones(n_samples) / n_samples
        
        for m in range(self.n_estimators):
            # 训练弱分类器
            clf = DecisionTreeClassifier(max_depth=1)
            clf.fit(X, y, sample_weight=weights)
            
            # 计算加权错误率
            predictions = clf.predict(X)
            errors = (predictions != y).astype(float)
            error_rate = np.dot(weights, errors) / np.dot(weights, np.ones(n_samples))
            
            # 计算分类器权重
            alpha = 0.5 * np.log((1 - error_rate) / error_rate)
            self.alphas.append(alpha)
            self.classifiers.append(clf)
            
            # 更新样本权重
            weights *= np.exp(-alpha * y * predictions)
            weights /= np.sum(weights)
            
        return self
        
    def predict(self, X):
        # 加权投票
        predictions = np.zeros(X.shape[0])
        for clf, alpha in zip(self.classifiers, self.alphas):
            predictions += alpha * clf.predict(X)
        return np.sign(predictions)
