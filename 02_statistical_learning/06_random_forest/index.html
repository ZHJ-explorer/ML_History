算法架构
多树集成结构

随机森林由多棵决策树组成。每棵树使用不同的 Bootstrap 样本训练，且在每个节点分裂时只考虑随机选择的特征子集。最终预测通过所有树的多数投票得出。

数学原理
核心公式
Bootstrap 采样
D_b = {(x_i^(b), y_i^(b))}_{i=1}^n, (x_i^(b), y_i^(b)) ~ Uniform(D), b = 1, ..., B
每棵树使用有放回抽样构建独立训练子集，约 36.8% 的样本未被覆盖（OOB 样本）。
随机特征选择（节点分裂）
S_t = RandomSubset( F, k), k = ⌊√m⌋
t* = argmax_{j ∈ S_t} ImpurityReduction(t, j)
在每个节点分裂时，从 m 个特征中随机选取 k 个候选特征，只在这些特征中寻找最优分裂点。
多数投票集成（分类）
ŷ = argmax_c Σ_{b=1}^B 1(h_b(x) = c)
B 棵树的预测结果通过多数投票聚合，得票最多的类别为最终预测。
平均值集成（回归）
ŷ = (1/B) Σ_{b=1}^B h_b(x)
回归任务中，取所有树预测值的算术平均作为最终输出。

import numpy as np
from decision_tree import DecisionTree

class RandomForest:
    """随机森林分类器。在Bagging基础上引入随机特征选择。"""
    
    def __init__(self, n_estimators=10, max_features=None):
        self.n_estimators = n_estimators
        self.max_features = max_features
        self.trees = []

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.max_features = self.max_features or int(np.sqrt(n_features))
        self.trees = []
        for _ in range(self.n_estimators):
            # Bootstrap 采样
            indices = np.random.choice(n_samples, n_samples, replace=True)
            X_sub, y_sub = X[indices], y[indices]
            clf = DecisionTree(max_depth=10)
            clf.fit(X_sub, y_sub)
            self.trees.append(clf)
        return self

    def predict(self, X):
        # 收集所有树的预测结果
        predictions = np.array([tree.predict(X) for tree in self.trees])
        # 多数投票
        return np.array([np.bincount(p).argmax() for p in predictions.T])

    def score(self, X, y):
        return np.mean(self.predict(X) == y)

学习心得
关键洞察

学到的知识

  • 随机森林的核心是双重随机性：数据随机（Bootstrap 采样）+ 特征随机（每节点选 √m 个特征），两者结合大幅降低树间相关性。
  • 与单棵决策树不同，随机森林中的每棵树不需要剪枝——即使过拟合的单棵树，通过集成也能获得稳健的泛化性能。
  • OOB（Out-of-Bag）错误率是随机森林的独特优势：每棵树约有 36.8% 的样本未被训练覆盖，这些样本可直接用于模型评估，无需额外验证集。
  • 特征重要性有两种计算方式：Gini 重要性（基于不纯度下降）和置换重要性（基于打乱特征后的性能下降），后者对高基数特征更公平。
  • 树的数量 B 增加会持续提升性能直至 plateau，但计算成本线性增长；实践中 B=10~100 通常已足够。

实现要点

  • 本项目基于已有的 DecisionTree 类构建，无需重写树分裂逻辑，只需添加 Bootstrap 采样和特征随机选择。
  • max_features 参数默认设为 √m（分类任务经验值），也可手动指定。
  • 投票通过 np.bincount(predictions).argmax() 高效实现，无需显式循环。
