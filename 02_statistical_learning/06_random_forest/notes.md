# 随机森林学习心得

## 关键洞察

- 随机森林的核心思想是**降低树之间的相关性**：Bagging 通过数据采样降低相关性，随机森林在此基础上进一步引入特征随机选择，双重降相关。
- 每棵树可以长得很大（甚至不剪枝），因为集成后的方差降低效应远大于单棵树的偏差。这与单一决策树需要剪枝防止过拟合形成鲜明对比。
- 特征随机选择的关键参数是 `max_features`（默认 √m）。对于分类任务，√m 是一个经验值；对于回归任务，通常使用 m（全部特征）。
- 随机森林的泛化误差上界与树的相关性和单个分类器的强度有关：相关性越低、单个树越强，集成效果越好。
- 置换重要性（Permutation Importance）比 Gini 重要性更可靠——Gini 偏向高基数特征，而置换重要性通过在测试集上打乱特征来评估，更加公平。
- 随机森林的一个优雅性质：OOB（Out-of-Bag）错误率可以作为无验证集的模型评估指标，因为每棵树约有 36.8% 的样本未被其 Bootstrap 样本覆盖。

## 实现要点

- 本项目基于已有的 `DecisionTree` 类，通过 Bootstrap 采样和随机特征子集构建多棵树，无需重写树分裂逻辑。
- 训练时的随机性来源有两个：(1) 每棵树的训练数据不同（Bootstrap 采样），(2) 每个节点分裂时考虑的候选特征不同（`np.random.choice` 选取）。
- `predict` 方法通过对所有树的预测结果进行多数投票（`np.bincount` + `argmax`）得到最终预测。
- `score` 方法直接复用 `predict` 结果计算准确率，无需额外实现。
- 交互式演示中，每棵树用不同的颜色区分，最终投票以条形图展示，直观体现集成机制。
