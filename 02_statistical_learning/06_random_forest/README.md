# 随机森林（Random Forest）

## 历史背景

Leo Breiman于2001年提出随机森林，是Bagging的改进版本。它在传统Bagging的基础上引入了随机特征选择机制——在每个节点分裂时只考虑随机子集的特征，从而进一步降低树之间的相关性，提升泛化能力。

## 数学原理

1. **随机采样**：有放回抽样构建多个子数据集（Bootstrap）
2. **随机特征选择**：每个节点分裂时，从 $m$ 个特征中随机选取 $k$ 个（通常 $k = \sqrt{m}$）
3. **投票集成**：$\hat{y} = \text{argmax}_c \sum_{i=1}^{B} \mathbb{1}(h_i(x) = c)$

## 代码实现

本目录实现了随机森林分类器，每个树使用不同Bootstrap样本和随机特征子集进行训练。
