历史背景
从问题到突破

Rumelhart、Hinton 和 Williams 在 1986 年发表于《Parallel Distributed Processing》的论文中推广了反向传播算法，标志着神经网络研究的复兴。虽然反向传播的思想早在 1970 年代就由 Werbos 提出，但直到 MLP 的普及才被广泛接受。

当时面临三大瓶颈：

  • 单层感知机无法解决 XOR 问题——Minsky & Papert 的批评导致神经网络研究进入寒冬
  • 没有有效的多隐层训练算法——误差无法从输出层回传到隐藏层
  • 计算能力不足——缺乏并行计算硬件支持大规模训练

核心突破在于反向传播算法：利用链式法则逐层传播误差，高效计算每一层的梯度，使多隐层网络的训练成为可能。

数学原理
核心公式
前向传播 · Forward Propagation
z[l] = W[l] · a[l−1] + b[l]
a[l] = σ(z[l])
对每一层 l，计算加权和 z，再经激活函数 σ 得到激活值 a。隐藏层使用 ReLU，输出层使用线性激活。
反向传播 · Backpropagation
δ[l] = (W[l+1])T · δ[l+1] ⊙ σ'(z[l])
∂L/∂W[l] = δ[l] · (a[l−1])T
∂L/∂b[l] = δ[l]
从输出层开始，沿链式法则逐层回传误差项 δ；梯度 = 误差 × 输入激活。⊙ 表示逐元素乘法（Hadamard 积）。
梯度更新 · Gradient Update
W[l] := W[l] − α · ∂L/∂W[l]
b[l] := b[l] − α · ∂L/∂b[l]
沿梯度反方向更新权重和偏置，α 为学习率。学习率过大导致 NaN，过小导致收敛缓慢。
ReLU 激活函数 · ReLU
σ(z) = max(0, z)
σ'(z) = { 1, if z > 0; 0, if z ≤ 0 }
ReLU 在正区间梯度恒为 1，有效缓解梯度消失问题；计算简单，已成为最主流的隐藏层激活函数。

import numpy as np

class MLP:
    """多层感知机，使用反向传播训练。"""
    def __init__(self, layer_sizes, learning_rate=0.01, max_iter=1000):
        self.layer_sizes = layer_sizes
        self.learning_rate = learning_rate
        self.max_iter = max_iter
        self.weights = []
        self.biases = []
        self._init_weights()

    def _init_weights(self):
        for i in range(len(self.layer_sizes) - 1):
            self.weights.append(np.random.randn(self.layer_sizes[i], self.layer_sizes[i+1]) * 0.01)
            self.biases.append(np.zeros(self.layer_sizes[i+1]))

    def _relu(self, z):
        return np.maximum(0, z)

    def _relu_derivative(self, z):
        return (z > 0).astype(float)

    def _forward(self, X):
        activations = [X]
        z_values = []
        for i in range(len(self.weights)):
            z = np.dot(activations[-1], self.weights[i]) + self.biases[i]
            z_values.append(z)
            if i < len(self.weights) - 1:
                a = self._relu(z)
            else:
                a = z
            activations.append(a)
        return activations, z_values

    def _backward(self, X, y, activations, z_values):
        m = X.shape[0]
        deltas = [None] * len(self.weights)
        output = activations[-1]
        deltas[-1] = (output - y) / m
        for i in range(len(self.weights) - 2, -1, -1):
            deltas[i] = np.dot(deltas[i+1], self.weights[i+1].T) * self._relu_derivative(z_values[i])
        for i in range(len(self.weights)):
            self.weights[i] -= self.learning_rate * np.dot(activations[i].T, deltas[i])
            self.biases[i] -= self.learning_rate * np.sum(deltas[i], axis=0)

算法对比
反向传播 vs 数值微分

数值微分

对每个参数计算偏导数：∂L/∂wᵢ ≈ (L(wᵢ+ε) − L(wᵢ−ε)) / 2ε。

复杂度 O(n)，n 为参数数量。参数越多，计算量线性增长。对于百万级参数的网络完全不切实际。

反向传播

通过链式法则，从输出层逐层回传误差项 δ，一次性计算所有梯度。

复杂度 O(1) 次前向+反向遍历，与参数数量无关。这是 MLP 能训练深层网络的关键。

历史局限与影响
从困境到奠基

历史局限性：深层网络面临梯度消失问题——越靠近输入层的梯度越小，导致底层权重几乎不更新。此外，梯度下降容易陷入局部最优，且需要大量标注数据。

解决方案：ReLU 激活函数在正区间梯度恒为 1，有效缓解梯度消失；Batch Normalization 稳定各层分布；残差连接（ResNet）直接打通梯度通路。

历史影响：MLP 与反向传播奠定了深度学习的基础，直接启发了现代深度学习框架（TensorFlow、PyTorch）的设计。几乎所有后续模型——CNN、RNN、Transformer——都依赖反向传播进行训练。

学习心得
关键洞察

学到的知识

  • 反向传播是链式法则的优雅应用——将全局梯度分解为逐层局部梯度的乘积
  • 梯度下降需要仔细选择学习率：太大导致震荡或 NaN，太小导致收敛缓慢
  • ReLU 激活函数解决了深层网络的梯度消失问题，计算简单且效果显著
  • 权重初始化至关重要：太小的初始值导致梯度消失，太大的初始值导致溢出

踩坑记录

  • 权重初始化很重要：太小导致收敛慢，太大会导致 NaN——推荐使用 0.01 缩放
  • 输出层需要 One-hot 编码：多分类任务中，标签需转为 [1,0,0] 形式而非标量
  • 训练 XOR 问题时收敛不稳定：需要更多迭代次数（10000+）或调整学习率

思考题答案

  • 为什么反向传播比数值微分更高效？ 数值微分对 n 个参数需计算 2n 次前向传播（O(n)）；反向传播只需一次前向+一次反向（O(1)），复杂度与参数数量无关。
  • 梯度消失问题如何解决？ 使用 ReLU 等非线性激活函数；使用 Batch Normalization 稳定层间分布；使用残差连接直接传导梯度。
  • 为什么 ReLU 成为最常用的激活函数？ 计算简单（只需比较 0）；在正区间梯度恒为 1，有效缓解梯度消失；产生稀疏激活，具有正则化效果。
