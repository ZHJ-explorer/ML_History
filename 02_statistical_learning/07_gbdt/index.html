数学原理
核心公式
初始化
f₀(x) = argminγ Σi L(yi, γ)
选择常数项使损失函数最小化，通常取训练标签的均值（回归）或逻辑值（分类）
迭代优化 — 第 m 步
rim = −[∂L(yi, f(xi)) / ∂f(xi)]f=fm−1
hm = argmin Σi (yi − h(xi))²
fm(x) = fm−1(x) + ν · hm(x)
计算负梯度（伪残差）→ 用决策树拟合 → 按学习率 ν 更新模型
最终预测
F(x) = Σm=1M ν · hm(x)
M 棵树的加权求和，ν 为学习率（shrinkage），控制每棵树的贡献权重

class DecisionTree:
    def fit(self, X, y):
        # 构建决策树拟合目标值
        self.root = self._build_tree(X, y)
        return self
    
    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in X])


class GBDT:
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3):
        self.n_estimators = n_estimators
        self.learning_rate = learning_rate
        self.trees = []
    
    def fit(self, X, y):
        self.f₀ = np.mean(y)  # 初始化
        self.predictions = np.full_like(y, self.f₀)
        
        for m in range(self.n_estimators):
            # 计算负梯度（伪残差）
            residuals = y - self.predictions
            
            # 用决策树拟合残差
            tree = DecisionTree(max_depth=self.max_depth)
            tree.fit(X, residuals)
            
            # 更新预测
            predictions = tree.predict(X)
            self.predictions += self.learning_rate * predictions
            self.trees.append(tree)
    
    def predict(self, X):
        return self.f₀ + self.learning_rate * sum(
            tree.predict(X) for tree in self.trees
        )
模型对比
GBDT vs 随机森林

GBDT

串行集成：每棵树拟合前一轮的残差， Sequential 学习
偏差-方差权衡：低偏差，可通过增加树数量降低误差
学习率：引入 shrinkage 防止过拟合，需要更多树
适用场景：结构化数据竞赛、精调任务

随机森林

并行集成：多棵树独立训练，可并行化
特征采样：每棵树只用部分特征，增加多样性
投票机制：通过多数投票或平均预测
适用场景：快速基线、高维数据、防过拟合

学习心得
关键洞察

学到的知识

  • GBDT 的核心思想是用梯度下降优化任意可微损失函数，而不仅是平方损失
  • 每棵决策树拟合的是前一阶段的负梯度（伪残差），而非原始标签
  • 学习率（shrinkage）是控制过拟合的关键超参数，较小的学习率通常需要更多迭代
  • GBDT 对异常值和缺失值有一定鲁棒性，适合处理真实世界数据
  • XGBoost 和 LightGBM 在 GBDT 基础上引入了正则化、直方图优化等创新

思考题

  • GBDT 和随机森林有什么区别？为什么 GBDT 通常效果更好？
  • 学习率（shrinkage）在 GBDT 中的作用是什么？如何选择合适的学习率？
  • 为什么 GBDT 可以用梯度下降来训练决策树？
