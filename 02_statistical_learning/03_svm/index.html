历史背景
从问题到突破

Vapnik 与 Chervonenkis 于 1992 年正式提出支持向量机，这是统计学习理论的杰出代表。当时神经网络正处于研究低谷期，学界需要一种具有严格理论保证的分类方法。

SVM 基于结构风险最小化原则，试图在模型复杂度和学习能力之间取得平衡。其核心思想是寻找一个最大间隔超平面，使不同类别的样本尽可能远离决策边界，从而提高泛化能力。

核技巧是 SVM 的另一大突破：通过核函数将低维不可分数据映射到高维空间，使其在高维空间中线性可分，而无需显式计算高维映射。

数学原理
核心公式
硬间隔 SVM · Hard Margin
minw,b (1/2)||w||²    s.t.   yi(wTxi + b) ≥ 1,   ∀i
要求所有样本被正确分类且间隔 ≥ 1；仅适用于线性可分数据。
软间隔 SVM · Soft Margin
minw,b,ξ (1/2)||w||² + C Σiξi    s.t.   yi(wTxi + b) ≥ 1 − ξi,   ξi ≥ 0
C 控制间隔最大化与误分类惩罚的权衡：C 越大，对误分类越敏感；C 越小，间隔越宽但容忍更多错误。
对偶问题 · Dual Formulation
maxα Σiαi − (1/2) Σi,j αiαjyiyj(xiTxj)    s.t.   0 ≤ αi ≤ C,   Σiαiyi = 0
对偶形式使核技巧成为可能——只需计算样本间内积，无需显式高维映射。只有 αi > 0 的样本（支持向量）影响最终决策边界。
核函数 · Kernel Functions
K(x, x') = φ(x)Tφ(x')
线性核：K(x,x') = xTx'  |  RBF 核（高斯）：K(x,x') = exp(−γ||x − x'||²)  |  多项式核：K(x,x') = (xTx' + 1)d

import numpy as np

class SVM:
    """使用简化版 SMO 算法求解的 SVM 分类器。"""
    def __init__(self, C=1.0, kernel='linear', gamma=None):
        self.C = C
        self.kernel = kernel
        self.gamma = gamma
        self.alphas = None
        self.b = 0
        self.support_vectors = None
        self.labels = None

    def _kernel(self, X1, X2):
        if self.kernel == 'linear':
            return np.dot(X1, X2.T)
        elif self.kernel == 'rbf':
            gamma = self.gamma if self.gamma else 1.0 / X1.shape[1]
            sq_dists = np.sum(X1**2, axis=1).reshape(-1, 1) + np.sum(X2**2, axis=1) - 2 * np.dot(X1, X2.T)
            return np.exp(-gamma * sq_dists)
        return np.dot(X1, X2.T)

    def fit(self, X, y):
        n = X.shape[0]
        self.alphas = np.zeros(n)
        for epoch in range(100):
            for i in range(n):
                # SMO 双乘子优化循环（简化版）
                ei = np.dot(self.alphas * y, self._kernel(X, X)[i]) + self.b - y[i]
                if (y[i] * ei < -1e-5 and self.alphas[i] < self.C) or \# could change
                   (y[i] * ei > 1e-5 and self.alphas[i] > 0):
                    j = np.random.randint(n)
                    # ... 更新 alpha_i, alpha_j, b
        # 提取支持向量
        sv_mask = self.alphas > 1e-5
        self.support_vectors = X[sv_mask]
        self.labels = y[sv_mask]

    def predict(self, X):
        return np.sign(np.dot(X, self.support_vectors.T) * (self.alphas * self.labels) + self.b)
    def score(self, X, y):
        return np.mean(self.predict(X) == y)

线性核 vs RBF 核对比

上方 SVG 提供了完整的交互式演示。切换到 RBF 核后，分类边界不再是直线，而是能够包围任意形状的曲线。拖动 C 参数滑块观察硬间隔（C 大）与软间隔（C 小）的区别；调节 γ 控制 RBF 核的局部性。

线性核（Linear）

决策边界为直线，适用于线性可分数据。计算简单、效率高，但无法处理复杂分布。对应核函数 K(x,x') = xᵀx'

RBF 核（高斯）

决策边界为曲线，能将数据映射到无限维空间。γ 控制局部性：γ 大→边界紧贴数据点（易过拟合），γ 小→边界平滑（欠拟合）。对应核函数 K(x,x') = exp(−γ||x−x'||²)

硬间隔 SVM

C 取值较大时，模型严格惩罚所有误分类样本，只接受完美分隔的超平面。对噪声和异常值非常敏感，要求数据严格线性可分。

软间隔 SVM

C 取值较小时，模型容忍部分误分类，换取更宽的间隔。通过松弛变量 ξᵢ 平衡间隔宽度与分类误差，显著提高泛化能力。

学习心得
关键洞察

学到的知识

  • SVM 通过最大化间隔提高泛化能力——间隔越宽，模型越稳健
  • 核技巧可以将低维不可分数据映射到高维空间使其线性可分，核函数直接计算高维内积，无需显式映射
  • 支持向量是决定分类边界的关键样本——只有 αi > 0 的样本影响最终超平面
  • C 控制正则化强度，γ 控制 RBF 核的局部性，二者均需要仔细调优

踩坑记录

  • 简化版 SMO 算法实现复杂，收敛性不稳定——生产环境建议使用 sklearn.svm.SVC
  • RBF 核的 γ 参数需要仔细调优：γ 过大导致过拟合（边界扭曲），过小导致欠拟合（近似线性）
  • SVM 训练复杂度为 O(n²) 到 O(n³)，大规模数据上训练缓慢，可考虑线性核或近似方法

思考题答案

  • 核技巧的原理是什么？将低维不可分的数据映射到高维空间使其线性可分；核函数直接计算高维内积，无需显式映射（"核 trick"）。
  • SVM 和感知机有什么区别？感知机寻找任意分隔超平面；SVM 寻找最大间隔超平面，泛化能力更强。
  • 为什么 SVM 适合小样本学习？结构风险最小化原则——只依赖支持向量，不受数据分布影响，在高维空间仍能保持良好的泛化性。
