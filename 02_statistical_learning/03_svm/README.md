# 支持向量机（SVM）

## 历史背景

支持向量机由Vapnik和Chervonenkis于1992年提出，是统计学习理论的杰出代表。SVM基于结构风险最小化原则，试图在复杂度和学习能力之间取得平衡。

**当时的问题**：
- 神经网络缺乏理论保证
- 需要更好的泛化能力
- 核方法需要统一框架

**核心突破**：
- 最大间隔分类器
- 核技巧处理非线性问题

## 数学原理

### 硬间隔SVM

$$\min_{w,b} \frac{1}{2}||w||^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \geq 1$$

### 软间隔SVM

$$\min_{w,b} \frac{1}{2}||w||^2 + C\sum_i \xi_i$$

### 对偶问题

$$\max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$$

### 核函数

$$K(x, x') = \phi(x)^T \phi(x')$$

常用核函数：
- 线性核：$K(x, x') = x^T x'$
- RBF核：$K(x, x') = \exp(-\gamma||x - x'||^2)$

## 历史局限性

1. 训练复杂度高：O(n²)到O(n³)
2. 对参数敏感：C和γ需要调优
3. 大规模数据难以训练

## 历史影响

- 直接启发了核方法的研究
- 为深度学习之前的最佳分类器
