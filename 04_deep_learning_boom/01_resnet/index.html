网络架构
ResNet-18 完整架构

ResNet-18 包含 10 个卷积层（不含 1×1 降维层）+ 1 个全连接层，共 18 层可学习参数。使用 Basic Block，每个卷积层后都跟随 Batch Normalization。

输入层 Conv7×7 → BN → ReLU → MaxPool 3×3 64 ch
Layer 1 Conv3×3 → BN → ReLU → Conv3×3 → BN + skip → ReLU ×2, 64 ch
Layer 2 Conv3×3 → BN → ReLU → Conv3×3 → BN + skip → ReLU ×2, 128 ch (stride=2)
Layer 3 Conv3×3 → BN → ReLU → Conv3×3 → BN + skip → ReLU ×2, 256 ch (stride=2)
Layer 4 Conv3×3 → BN → ReLU → Conv3×3 → BN + skip → ReLU ×2, 512 ch (stride=2)
输出 AvgPool 7×7 → Linear 512→10 CIFAR-10

历史背景
从退化问题到解决方案

Kaiming He 等人在 2015 年发表的 ResNet，解决了深度神经网络训练中的退化问题（degradation problem）：随着网络加深，训练误差反而上升。

在此之前，VGGNet（2014）将网络推到 19 层取得了成功，但更深的网络却无法训练。ResNet 的关键洞察是：恒等映射应该是最优解的退化情况——如果当前层不需要做任何变换，网络应该能够轻松跳过它。

传统深度网络的问题

层数增加 → 梯度需要通过更多层相乘 → 梯度消失/爆炸 → 深层权重无法有效更新 → 准确率饱和后下降

ResNet 的突破

添加跳跃连接 → 梯度有直达路径 → 深层网络可以训练 → 152 层仍能有效学习 → ImageNet 冠军

数学原理
核心公式
残差块输出 · Residual Block Output
y = F(x, {Wi}) + x
f(y) = ReLU(y)
F(x) 是残差函数（通常 2-3 个卷积层），x 通过恒等映射直接连接到输出，实现"快捷通道"。
梯度传播对比 · Gradient Flow
无残差: ∂L/∂x = ∂L/∂y · Wn · ... · W2 · W1
有残差: ∂L/∂x = ∂L/∂y · (Wn · ... · W1 + 1)
跳跃连接在反向传播时提供 "+1" 项，确保梯度不会因多层连乘而消失。
Bottleneck Block · 降维-升维
x → Conv1×1(↓d) → Conv3×3(保持) → Conv1×1(↑d) → +x
ResNet-50/101/152 使用 Bottleneck Block：先用 1×1 卷积降维，再 3×3 卷积处理，最后升维回原维度。
维度不匹配时的 Shortcut
F(x) + Ws·x   (when dimensions differ)
Ws: 1×1 convolution with stride
当输入输出通道数或空间尺寸不同时，shortcut 路径使用 1×1 卷积进行升维/降维对齐。

import torch
import torch.nn as nn


class BasicBlock(nn.Module):
    """ResNet 基础块：两个 3×3 卷积 + 跳跃连接"""
    expansion = 1

    def __init__(self, in_channels, out_channels, stride=1):
        super().__span class="fn">init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        # 跳跃连接：维度不匹配时使用 1×1 卷积
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != self.expansion * out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # ← 核心：残差连接
        out = torch.relu(out)
        return out


class ResNet(nn.Module):
    """ResNet 主网络"""
    def __init__(self, block, num_blocks, num_classes=10):
        super().__span class="fn">init__()
        self.in_channels = 64
        self.conv1 = nn.Conv2d(3, 64, 3, 1, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        self.layer1 = self._make_layer(block, 64, num_blocks[0], stride=1)
        self.layer2 = self._make_layer(block, 128, num_blocks[1], stride=2)
        self.layer3 = self._make_layer(block, 256, num_blocks[2], stride=2)
        self.layer4 = self._make_layer(block, 512, num_blocks[3], stride=2)
        self.linear = nn.Linear(512 * block.expansion, num_classes)

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.layer1(out)
        out = self.layer2(out)
        out = self.layer3(out)
        out = self.layer4(out)
        out = nn.functional.avg_pool2d(out, 4)
        out = out.view(out.size(0), -1)
        return self.linear(out)


def resnet18():
    return ResNet(BasicBlock, [2, 2, 2, 2])

学习心得
关键洞察

学到的知识

  • 残差学习的本质：不是学习完整映射 H(x)，而是学习增量 F(x) = H(x) - x，让恒等映射成为可选的退化情况
  • 梯度高速通道：跳跃连接在反向传播时提供 +1 项，确保梯度不会因多层连乘而指数级衰减
  • 退化 vs 过拟合：深层网络准确率下降是退化问题（训练困难），不是过拟合——训练误差也上升
  • Batch Normalization 配合：ResNet 在卷积后立即使用 BN，有助于稳定深层网络训练
  • 思想的普适性：残差连接已成为现代深度学习的基础组件，从 Transformer 到 Diffusion Model 都在使用
  • 工程意义：让网络可以"任意加深"而不担心性能退化，为后续研究打开了空间

实现要点

  • 维度不匹配时，shortcut 路径需添加 1×1 卷积进行升维/降维
  • Basic Block 用于 ResNet-18/34，Bottleneck Block 用于 ResNet-50+
  • CIFAR-10 上使用 3×3 卷积代替 ImageNet 的 7×7 卷积和最大池化
  • 每个卷积层后都紧跟 BN，最后才使用 ReLU（Post-activation ResNet）
