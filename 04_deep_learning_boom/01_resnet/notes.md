# 学习心得

## 关键洞察

- **残差连接的本质**：不是简单地跳过几层，而是让网络学习"增量"——当当前层无法进一步提升时，至少可以保持恒等映射。
- **梯度流改善**：跳跃连接在反向传播时提供了一条梯度直达路径，解决了深层网络的梯度消失问题。
- **退化问题**：ResNet 揭示了一个反直觉现象——更深的网络不一定更好，但如果设计得当，深层网络可以轻易超越浅层网络。
- **Batch Normalization 的重要性**：论文中 BN 与残差连接配合使用，加速了训练收敛。

## 实现要点

- 使用 `nn.BatchNorm2d` 在卷积后、激活前进行归一化
- 当输入输出维度不匹配时，shortcut 路径需要 1×1 卷积进行升维
- ResNet-18/34 使用 BasicBlock，ResNet-50+ 使用 BottleneckBlock

## 思考

残差思想已经超越了 CNN，成为现代深度学习的基础组件。Transformer、Diffusion Model 等都大量使用了残差连接。
