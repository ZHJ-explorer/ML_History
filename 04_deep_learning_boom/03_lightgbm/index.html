直方图算法

将连续特征值离散化为固定数量的bin（默认256），构建直方图后用差值加速寻找最优分割点，时间复杂度从 O(data×features) 降至 O(bins×features)。

🎯

GOSS 单边采样

保留梯度大的样本（信息量大），随机采样梯度小的样本，在保持信息量的同时大幅减少计算量，使内存占用降低约6倍。

🔗

EFB 特征捆绑

将互斥特征（很少同时非零）捆绑为一个特征，显著减少特征数量。采用贪心冲突图算法自动识别可捆绑特征。

历史背景
从问题到突破

Microsoft 在 2017 年提出 LightGBM，旨在解决 XGBoost 在大规模数据上的训练瓶颈。

XGBoost 使用基于排序的精确分裂算法，时间复杂度为 O(data × features)，面对千万级样本时训练缓慢且内存开销大。LightGBM 通过三项关键技术彻底改变了这一局面。

数学原理
核心公式
直方图分裂增益（简化）
gain(s) = (LeftGrad² / (LeftHess + ε)) + (RightGrad² / (RightHess + ε))
使用直方图差值：Right = Parent − Left，避免重复遍历，O(1) 更新
GOSS 加权修正
w_i = (1 − a) / a  if  i ∈ 小梯度采样集
对采样的小梯度样本赋予更高权重，保证统计期望不变
互斥特征捆绑
F_bundle = Σ F_i  (bundle内特征互斥: F_i · F_j = 0)
通过冲突图最大团算法找到互斥特征集合，合并后共享同一histogram

class LightGBM:
    def __init__(self, n_estimators=50, max_depth=3, learning_rate=0.01):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.learning_rate = learning_rate
        self.trees = []
        self.base_score = 0.5

    def fit(self, X, y):
        self.trees = []
        n = len(y)
        self.base_score = np.mean(y)
        initial_pred = np.log(self.base_score / (1 - self.base_score + 1e-16))
        predictions = np.full(n, initial_pred)

        for i in range(self.n_estimators):
            probs = self._sigmoid(predictions)
            gradients = probs - y
            hessians = probs * (1 - probs) + 1e-8

            tree = LightGBMTree(max_depth=self.max_depth)
            tree.fit(X, gradients, hessians)

            predictions += self.learning_rate * tree.predict(X)
            self.trees.append(tree)
        return self

    def predict(self, X):
        n = X.shape[0]
        initial_pred = np.log(self.base_score / (1 - self.base_score + 1e-16))
        predictions = np.full(n, initial_pred)
        for tree in self.trees:
            predictions += self.learning_rate * tree.predict(X)
        return (self._sigmoid(predictions) >= 0.5).astype(int)

学习心得
关键洞察

学到的知识

  • LightGBM 通过直方图算法将连续特征离散化，大幅减少分裂搜索的计算量
  • GOSS 单边梯度采样：保留梯度大的样本，随机采样梯度小的样本，用加权修正保证无偏
  • EFB 互斥特征捆绑：将很少同时非零的特征合并，显著降低特征维度（尤其适合One-Hot编码）
  • Leaf-wise 生长策略相比 XGBoost 的 level-wise，能在相同分裂次数下获得更低误差
  • 直接支持类别特征，无需 One-Hot 编码，避免维度爆炸
  • 在 Kaggle 结构化数据竞赛中，LightGBM 常与 XGBoost 并列为首选基线模型
