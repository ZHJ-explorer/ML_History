单向 Transformer 解码器

GPT-1 采用纯 Decoder-only 架构，核心是一个带有 causal mask 的 Multi-Head Self-Attention。每个位置只能关注自身及之前的位置，保证自回归生成的单向性。

注意力机制
Causal Attention Mask

每个解码器层内部的 Self-Attention 使用 下三角矩阵 作为 mask，确保位置 i 只能看到位置 ≤ i 的信息。图中高亮行展示当前 token 能 attend 到的范围。

历史背景
从问题到突破

OpenAI 在 2018 年发表了 《Improving Language Understanding by Generative Pre-Training》（GPT-1），首次提出 预训练 + 微调 的范式。

在此之前，NLP 任务通常从零开始训练专用模型。GPT-1 证明：先在大规模无标注文本（BookCorpus, 980M词）上做语言模型预训练，再在下游任务上微调，可以显著提升泛化能力。

Attention(Q, K, V) = softmax(QKT / √dk) · V
GPT-1 中使用 Multi-Head Attention：将 Q/K/V 拆分为 h=12 个头，并行计算后拼接
Causal Mask

下三角 mask 确保位置 i 的预测只依赖于位置 ≤ i 的历史 token
Language Modeling Objective
ℒ = − Σt log P(wt | w<t; θ)

代码实现
model.py 核心逻辑
Python · model.py 
class GPT1(nn.Module):
    def __init__(self, vocab_size=50257, d_model=768,
                 num_heads=12, num_layers=12, max_seq_len=1024):
        super().__span class="fn">init__()
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.position_embedding = nn.Embedding(max_seq_len, d_model)

        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=num_heads,
            dim_feedforward=3072, dropout=0.1
        )
        self.transformer_encoder = nn.TransformerEncoder(
            encoder_layer, num_layers=num_layers
        )
        self.ln_final = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab_size, bias=False)

    def forward(self, input_ids, attention_mask=None):
        batch_size, seq_len = input_ids.size()
        token_emb = self.token_embedding(input_ids)
        pos_ids = torch.arange(seq_len).unsqueeze(0).expand(batch_size, -1)
        pos_emb = self.position_embedding(pos_ids)
        x = token_emb + pos_emb
        x = self.transformer_encoder(x)
        x = self.ln_final(x)
        logits = self.head(x)
        return logits

注：实际 PyTorch TransformerEncoder 需要传入 mask 参数以实现 causal mask；此处展示简化结构。

对比分析
GPT-1 vs BERT

GPT-1（单向）

Decoder-only 架构，causal mask 限制只看左侧历史。

优势：天然适合文本生成、续写任务。
预训练：左向语言建模（LM）。
下游：fine-tune 后可用于文本分类、问答。

BERT（双向）

Encoder-only 架构，双向注意力看到完整上下文。

优势：在 NLU 任务（GLUE、SQuAD）上表现优异。
预训练：MLM（掩码语言建模）+ NSP。
局限：不适合直接用于文本生成。

学习心得
关键洞察

学到的知识

  • GPT-1 首次将「预训练 + 微调」范式成功应用于 NLP，开启了大模型时代
  • 单向（causal）vs 双向（masked）语言建模是生成任务和理解任务的根本分歧点
  • 117M 参数在当时已展现出零样本（zero-shot）迁移能力
  • Position embedding 的引入使模型能够感知 token 顺序
  • Weight tying（输入/输出共享 embedding 矩阵）是 GPT 系列的标准做法

常见误区

  • GPT-1 使用 learned positional embedding，而非 Transformer 原版的 sinusoidal encoding
  • GPT-1 的 FFN 使用 GELU 激活函数（与 BERT 一致）；SwiGLU 等 GLU 变体是 PaLM / LLaMA 时代的改进
  • GPT-1 并未使用 Layer Scale 或 RMSNorm，这些是后续工作（Gopher、PaLM）的改进
