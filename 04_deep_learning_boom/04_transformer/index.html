Encoder-Decoder 结构

Transformer 由 编码器（Encoder）和 解码器（Decoder）两部分堆叠而成，每部分包含 N 层（论文中 N=6）。编码器处理输入序列，解码器生成输出序列。

核心机制
Self-Attention 与 Q/K/V 计算

自注意力的核心思想是：每个位置都问自己"哪些其他位置对我最重要？"。通过 Query (Q)、Key (K)、Value (V) 三个矩阵，计算序列中任意两个位置之间的关联度。

数学原理
核心公式
Scaled Dot-Product Attention
Attention(Q, K, V) = softmax(QKT / √dk) · V
除以 √dₖ 防止点积过大导致 softmax 梯度消失。dₖ 是 Key 向量的维度。
Multi-Head Attention
MultiHead(Q,K,V) = Concat(head₁, ..., headh) · WO
其中 headi = Attention(QWiQ, KWiK, VWiV)
每个头使用不同的投影矩阵，捕捉不同类型的语义关系。h=8 为默认头数。
Positional Encoding (Sinusoidal)
PE(pos, 2i) = sin(pos / 100002i/dmodel)
PE(pos, 2i+1) = cos(pos / 100002i/dmodel)
用正弦/余弦函数注入位置信息，无需学习参数。不同位置产生不同的编码向量。
Layer Normalization
LayerNorm(x) = (x - μ) / σ · γ + β
对每个位置的 特征维度 做归一化（而非 Batch 维度），使深层训练更稳定。
代码实现
PyTorch 核心实现
Python · transformer.py 
import torch
import torch.nn as nn
import math

class ScaledDotProductAttention(nn.Module):
    def forward(self, Q, K, V, mask=None):
        d_k = Q.size(-1)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        attn = torch.softmax(scores, dim=-1)
        return torch.matmul(attn, V), attn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__span class="fn">init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        batch_size = x.size(0)
        Q = self.W_q(x).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        attn_output, attn_weights = ScaledDotProductAttention(self)(Q, K, V, mask)
        out = attn_output.transpose(1, 2).contiguous().view(batch_size, -1, self.num_heads * self.d_k)
        return self.W_o(out), attn_weights

学习心得
关键洞察

学到的知识

  • Transformer 的核心是自注意力机制，通过 Q/K/V 三个矩阵计算 Token 之间的关联度
  • 多头注意力允许模型在不同子空间中同时关注不同位置的信息
  • 位置编码解决了序列顺序问题，用正弦/余弦函数而非学习参数注入位置信息
  • 残差连接 + Layer Normalization 是训练深层 Transformer 的关键技巧
  • Transformer 的 O(n²) 注意力复杂度是后续长序列模型的优化方向

关键洞察

  • 自注意力的本质是：每个位置都问自己"哪些其他位置对我最重要？"
  • Q（Query）代表当前词的"查询需求"，K（Key）代表其他词的"可被查询属性"，V（Value）是被传递的"实际内容"
  • 多头并行的直觉：就像多人从不同角度解读一句话，各自关注不同的语义维度
  • LayerNorm 作用在特征维度上（而非 Batch 维度），使训练更稳定

与前后模型的关联

  • 承前：比 RNN/LSTM 更高效地处理长距离依赖，解决了梯度消失问题
  • 启后：BERT 在此基础上加入双向预训练；GPT 加入因果掩码实现单向生成；T5/BERT 等衍生模型进一步扩展了应用范围
