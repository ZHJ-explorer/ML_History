核心架构
梯度提升树结构

XGBoost 的核心思想是用一棵棵决策树依次学习前序模型的残差。每一轮迭代都拟合当前模型的负梯度（一阶梯度）和二阶导数信息。

图：XGBoost 使用多棵决策树串联合成最终预测结果

数学原理
二阶泰勒展开优化

XGBoost 的关键创新在于使用二阶泰勒展开近似损失函数。通过同时利用一阶导数（梯度）和二阶导数（Hessian），可以更早收敛并获得更精确的树分裂点选择。

图：XGBoost 使用二阶泰勒展开精确逼近损失函数

正则化
防止过拟合的正则化项

XGBoost 在目标函数中显式加入正则化项，控制树的复杂度和叶子权重，从而有效防止过拟合。这是 XGBoost 相比传统 GBDT 的重要改进。

目标函数
Obj = ∑ i l(yi, f̂i) + Ω(f)

Ω(f) = γT + ½λ ∑j wj2
γ (Gamma) · 叶子节点惩罚
控制树的复杂度。γ 越大，树越简单。只有当分裂带来的增益大于 γ 时才会继续分裂。
λ (Lambda) · L2 正则化
对叶子节点的权重施加 L2 正则化，防止单个叶子权重过大，提升模型泛化能力。

数学原理
核心公式
一阶泰勒展开
f̂i = ∑k=1K fk(xi)
预测值 = 所有树的输出之和
二阶泰勒展开目标函数
Obj ≈ ∑i[ l(yi, f̂i(t)) + gift(xi) + ½hift2(xi) ] + Ω(ft)

其中 gi = ∂l(yi, f̂i(t-1)) / ∂f̂i(t-1) ， hi = ∂²l(yi, f̂i(t-1)) / ∂f̂i2(t-1)
g 为梯度（一阶导数），h 为 Hessian（二阶导数）
叶子权重最优解
wj* = -Gj / (Hj + λ)
Gj = ∑i∈Ij gi，Hj = ∑i∈Ij hi，Ij 为叶子 j 的样本集合
分裂增益公式
Gain = ½[ (GL2 / (HL + λ)) + (GR2 / (HR + λ)) - (GTotal2 / (HTotal + λ)) ] - γ
只有当 Gain > 0 时才进行分裂，γ 惩罚新增叶子节点

学习心得
关键洞察

学到的知识

  • XGBoost 使用二阶泰勒展开比传统 GBDT 的仅一阶更精确，能更快收敛
  • 正则化项 γT + ½λΣw² 是 XGBoost 防止过拟合的关键创新
  • 分裂增益公式结合了一阶和二阶信息，使决策更准确
  • 叶子权重 wj* = -Gj/(Hj+λ) 是目标函数最优解
  • XGBoost 支持并行处理特征，但在树的构建上仍是串行的
  • 学习率（shrinkage）和树数量配合可以控制过拟合
