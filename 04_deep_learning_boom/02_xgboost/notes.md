# XGBoost 学习笔记

## 核心概念

### 梯度提升树

XGBoost 是梯度提升决策树（GBDT）的增强版本，通过串行添加决策树来逐步减少预测误差。

### 二阶优化

与传统 GBDT 只使用一阶梯度不同，XGBoost 同时利用一阶和二阶导数信息，使树分裂决策更精确。

### 正则化

XGBoost 的"X"代表 eXtreme，其核心创新之一是显式的正则化项，有效控制模型复杂度。

## 学习要点

1. **目标函数**：损失函数 + 正则化项
2. **泰勒展开**：用二阶近似替代原始损失函数
3. **树构建**：基于增益贪心算法寻找最优分裂
4. **叶子权重**：w* = -G/(H + λ)

## 实践建议

- 初始学习率设为 0.01-0.1
- max_depth 通常设为 3-6
- gamma 和 lambda 用于防止过拟合
- n_estimators 和学习率需要配合调优
