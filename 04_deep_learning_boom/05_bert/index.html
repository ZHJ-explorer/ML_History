历史背景
从问题到突破

Google Research 团队在 2018 年发表了《BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding》，提出了一种全新的语言模型预训练方法。

在此之前，语言模型主要分为两类：GPT 采用单向（从左到右）预训练，适合生成任务；ELMo 虽然使用了双向 LSTM，但其表示是静态的——同一个词在不同语境下得到相同的向量。

BERT 的突破：通过掩码语言模型（MLM）任务，让模型在预训练过程中随机遮蔽 15% 的 token，学习从双向上下文中预测被遮蔽的词。这使 BERT 能够生成真正语境敏感的语义表示。

BERT 在 11 项自然语言处理基准测试上刷新了记录，包括 GLUE、SQuAD 等，成为 NLP 领域的里程碑式工作。

预训练任务
MLM 与 NSP
Masked Language Model (MLM)
P(Wt | W≠t)
随机遮蔽 15% 的 token，学习从剩余双向上下文中预测被遮蔽的词。这是 BERT 获得深层语义理解的核心机制。
🎯 概率预测 🔄 双向上下文
Next Sentence Prediction (NSP)
P(SentenceB | SentenceA)
判断第二句话是否是第一句话的下一句。帮助模型理解句子间的逻辑关系，对问答和文本蕴含任务有帮助。
📝 二分类 🔗 句间关系
数学原理
核心公式
自注意力机制 (Self-Attention)
Attention(Q, K, V) = softmax(QKT / √dk)V
Q、K、V 分别为查询、键、值矩阵，dk 为键向量维度。BERT 使用 12 头并行注意力，每头维度 64。
多头注意力 (Multi-Head Attention)
MultiHead(Q,K,V) = Concat(head1, ..., headh)WO
headi = Attention(QWiQ, KWiK, VWiV)。通过多组线性投影，模型能在不同子空间中捕获多样化语义关系。
掩码语言模型损失
LMLM = -Σi∈M log P(wi | w≠i)
M 是被遮蔽 token 的集合。通过最大化被遮蔽位置的词概率，模型学习深层双向语义表示。
代码实现
model.py 核心逻辑

class BERT(nn.Module):
    def __init__(self, vocab_size=30522, d_model=768, 
                 num_heads=12, num_layers=12, max_seq_len=512):
        super().__init__()
        # 三种嵌入：词嵌入 + 位置嵌入 + 段落嵌入
        self.word_embedding = nn.Embedding(vocab_size, d_model)
        self.token_type_embedding = nn.Embedding(2, d_model)
        self.position_embedding = nn.Embedding(max_seq_len, d_model)
        
        # 12层 Transformer 编码器
        self.encoder_layers = nn.ModuleList([
            nn.TransformerEncoderLayer(
                d_model=d_model, nhead=num_heads,
                dim_feedforward=3072, dropout=0.1
            )
            for _ in range(num_layers)
        ])
        
        # 预训练任务头
        self.cls_head = nn.Linear(d_model, vocab_size)
        self.nsp_head = nn.Linear(d_model, 2)

    def forward(self, input_ids, token_type_ids=None, attention_mask=None):
        batch_size, seq_len = input_ids.size()
        
        # 嵌入叠加
        word_embeddings = self.word_embedding(input_ids)
        token_type_embeddings = self.token_type_embedding(
            token_type_ids if token_type_ids is not None else torch.zeros_like(input_ids)
        )
        position_ids = torch.arange(seq_len).unsqueeze(0).expand(batch_size, -1)
        position_embeddings = self.position_embedding(position_ids)
        
        embeddings = word_embeddings + token_type_embeddings + position_embeddings
        
        # 编码器堆叠
        output = embeddings
        for layer in self.encoder_layers:
            output = layer(output)
        
        cls_output = output[:, 0, :]  # [CLS] token 表示
        mlm_output = self.cls_head(cls_output)
        nsp_output = self.nsp_head(cls_output)
        
        return mlm_output, nsp_output

关键洞察

学到的知识

  • BERT 的双向预训练是 NLP 领域的里程碑，打破了 GPT 的单向局限
  • [CLS] token 用于句子级任务（如 NSP），而 [MASK] 位置输出用于词级预测
  • 词嵌入、位置嵌入、段落嵌入三者叠加，构成 BERT 的输入表示
  • 12层编码器 + 12头注意力的配置（BERT-base）平衡了性能与计算成本
  • 预训练 + 微调范式成为后续所有大模型的标准流程
